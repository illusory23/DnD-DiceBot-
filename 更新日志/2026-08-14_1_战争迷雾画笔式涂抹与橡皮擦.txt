【2026-08-14_1】战争迷雾改为画笔式涂抹与橡皮式部分擦除

修改文件：
- web/static/map.js
- web/templates/map.html
（备份：backups/2026-08-13_fog_brush/）

一、绘制逻辑改造（完全参考画笔逻辑）
- 之前：点击地图添加顶点"两点定线"式绘制，Shift+点击手动闭合，松开形成多边形面。
- 现在：按住鼠标拖动涂抹，涂抹的轨迹就是迷雾（与画笔画线完全一致），不做任何自动闭合。
- 迷雾线宽随画笔粗细滑块联动（画笔粗细 ×3，最小 16px）。
- 绘制过程中实时预览：白色半透明粗线显示涂抹效果。
- 单点点击也有效（画一个雾点）。

二、删除逻辑改造（完全参考橡皮擦逻辑，无切断无分裂）
- 新增"🧽 擦除迷雾"菜单项：按住拖动即擦除，与橡皮擦完全一致——在迷雾上挖洞，
  只抹掉经过路径的部分，雾线不断裂不分裂（无任何切断/裁剪算法）。
- 实现：擦除轨迹记录到 fogErasures，渲染时对迷雾 mask 做 destination-out 挖洞，
  数据层面雾仍是完整的一笔笔。
- 擦除判定修正（解决"擦除时雾缩小"）：改为矢量判定——擦除胶囊（半径 = 擦除半径 + 雾线宽一半）
  与雾线段相交的，该线段整条不再渲染（擦除处干净消失，无残边）。
  像素级挖洞（destination-out）在洞宽=雾宽时，鼠标稍有偏移就会留下细残边（视觉上"雾缩小"）；
  矢量判定彻底消除此问题：碰到即整段干净消失，未碰到完全不擦。
- 数据层面雾仍是一笔笔完整轨迹（fogStrokes 不变），渲染时动态跳过被擦线段，无切断无分裂。
- 旧闭合面数据仍用 destination-out 挖洞（历史数据兼容）。
- 擦除判定性能优化（修复雾多时绘制/擦除卡死）：
  - AABB 快速剔除：雾线段与擦除胶囊包围盒不相交则跳过距离计算。
  - 版本化缓存：每条雾线段的擦除判定结果按"已判定擦除轨迹数"增量缓存，
    新增擦除只重判增量部分，渲染时 O(1) 查缓存。
  - 实测用户现场数据量（11 笔雾 × 11 条擦除轨迹）：首次判定 60ms，之后渲染 0ms，
    新增擦除增量判定 24ms，绘制/擦除全程流畅。
  - 修复：单点擦除轨迹端点判定遗漏、线段版本共享导致的漏判（改为逐线段独立版本）。
- 擦除过程中所见即所得：正在擦的轨迹实时挖洞预览，松开鼠标后固化保存。
- 擦除预览：红色半透明粗线显示橡皮轨迹（参考画笔预览样式）+ 红色擦除圈光标。
- 遮盖检测联动：被挖洞区域的 token/文字框不再视为被迷雾遮盖（PL 视角重新可见）。
- 旧存档的闭合面数据：同样按挖洞处理（点在洞内部分不再遮盖）。

三、删除迷雾图层系统
- 移除多图层结构（fogLayers / fogLayerIdCounter / activeFogLayerId / 图层编号 / 重命名 / 新建图层 / 切换图层）。
- 数据模型简化为单数组 fogStrokes：[{points, closed}]，closed 仅旧存档闭合面使用。
- 图层面板中"迷雾图层列表 + 新建迷雾层按钮"改为单行"🌫 战争迷雾（可见/隐藏）"，DM 可点击切换显示。
- 迷雾下拉菜单精简为：绘制迷雾 / 擦除迷雾 / 启用迷雾 / 隐藏迷雾 / 删除迷雾。

四、多层迷雾单层合成（重叠不加深）
- 新增离屏 mask（不透明黑色画所有雾形状）+ destination-in 单层合成：
  多层迷雾重叠处的透明度不累加、不加深，永远保持单层效果。
- DM 视角：半透明（rgba 40,40,40,0.85），能清楚看到迷雾下的地图与 token。
- PL 视角：不透明（rgba 30,30,30,1），迷雾下被遮盖的 token/文字框不可见。
- 绘制中的涂抹预览同样进入单层合成，预览效果与最终一致。

五、PL 视角迷雾遮盖检测
- 涂抹轨迹：token/文字框 5 个探针点距轨迹任一线段 ≤ 线宽一半 → 视为被迷雾遮盖（隐藏）。
- 旧存档闭合面：沿用点在多边形内检测。
- 擦除挖洞区域（fogErasures）内的探针点不视为被遮盖——被橡皮擦掉的地方 PL 重新可见。

六、存档与同步兼容
- 新存档格式：fogStrokes + fogErasures + fogVisible；WebSocket/HTTP 同步格式：{strokes, erasures, visible}。
- 旧存档自动兼容：多图层 fogLayers 展平；旧 fogPolygons / {polygons, visible} / 纯数组格式仍可读取，旧闭合面仍按面显示和检测（无擦除洞）。
- 服务端 shared_state.py / app.py 无需改动（fog 键通用存储）。
- map.js 缓存版本号 v=46 → v=47，客户端需强制刷新一次页面。
