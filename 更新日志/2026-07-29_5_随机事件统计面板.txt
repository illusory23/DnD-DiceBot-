2026-07-29 随机事件界面右侧统计面板

━━━ 功能概述 ━━━
在跑团平台 Web 版的随机事件界面右侧增加可展开/收起的统计面板，
统计当前用户遭遇的各个事件**具体内容**的数量及概率，
每名用户只能看到自己的统计数据。

━━━ 统计内容 ━━━
- 按事件表分组（如"随机环境"、"随机人类"等）
- 每组内统计该表每个具体事件内容的出现次数
- 概率 = 该具体事件次数 / 全局总事件次数 × 100%
- 例：掷 hj6 出"雪坑"3次、掷 rl100 出"商队"2次，总5次
  则"雪坑"概率=60%，"商队"概率=40%

━━━ 修改文件 ━━━
1. 骰娘/web/app.py — 新增事件统计 API
   - POST /api/events/stats
     请求: {name, command, events: [{table, content}]}
     解析掷表输出文本中的具体事件内容（提取括号前短名称）
     按 (用户名 → 表名 → 事件内容) 三级结构累计计数
   - GET  /api/events/stats?name=xxx
     返回: {name, total, groups: [{table, dice, total_in_table, events: [{content, count, probability}]}]}
   - 数据存储: web/event_stats.json

2. 骰娘/web/templates/events.html — 前端界面与交互
   - 页面布局改为左侧主内容 + 右侧统计面板的双栏布局（flex）
   - 统计面板默认收起（42px 竖条），点击"📊 事件统计"展开
   - 展开时自动拉取该用户的服务器端统计数据
   - 每次掷事件后自动从输出文本解析事件内容并上报至统计 API
   - 统计面板展开时，每次掷事件成功自动刷新
   - 显示：摘要行（总事件数、事件表类型数）+ 按表分组的详情
   - 每组表格显示：事件内容、次数、概率(%)
   - 响应式：窄屏（≤900px）时统计面板移到主内容下方

━━━ 技术细节 ━━━
- 前端 parseEventsFromOutput() 用正则从输出文本解析所有事件行
  格式: "🎲 标签 [骰子: 值]\n   具体内容" 和 "↳ 🎲 ..."
- 后端 _extract_event_name() 提取"（"前的短名称作为统计键
  如 "商队（可交易）" → "商队"
- 用户身份来自 sessionStorage 中的 dnd_joined_room
- 统计数据在服务端 JSON 文件持久化，刷新/重开页面不丢失
- 无活跃用户时不记录统计（静默跳过）
