2026-08-16 第3次更新：我的收藏可点击跳转独立详情页

【问题】用户中心"我的收藏"列表项不可点击（原为 javascript:void(0)
占位，注释"收藏项仅展示"）——无法查看收藏的帖子/工坊详情

【需求】点击收藏项跳转到新页面显示详细内容（独立页面，非弹窗）

【实现】
1. 新增独立详情页路由（web/app.py）：
   - GET /post/<id>        → portal/post_detail.html（酒馆帖子详情）
   - GET /workshop/<id>    → portal/workshop_detail.html（工坊投稿详情）
2. 新增页面模板：
   - post_detail.html：标题/作者(头像)/时间/板块/正文/图片 + 点赞/收藏
     按钮（带计数、登录态高亮）+ 评论区（发表/删除，头像展示）+
     深色浅色主题切换，风格与用户中心一致
   - workshop_detail.html：标题/作者(头像)/时间/描述/下载按钮 +
     删除投稿（作者/管理员）+ 点赞/收藏 + 评论区
3. 用户中心收藏列表（user.html）：收藏项链接改为
   /post/<id>（帖子）与 /workshop/<id>（工坊），点击跳转新页面

【验证】
- /post/2、/workshop/1 → 200；不存在的 id 页面正常显示"不存在"提示
- 无头浏览器：帖子详情（标题/作者/内容/点赞收藏按钮/评论区/无JS错误）、
  工坊详情（标题/作者/描述/点赞按钮）全部通过
- 完整链路：用户中心登录 → 收藏帖子+工坊 → 收藏列表显示详情页链接 →
  点击收藏项 → 服务器日志确认跳转 GET /post/2 200 → 详情渲染正常
- 测试数据已清理
