1. 跑团平台身份冒用修复
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
问题：从浏览器历史记录直接进入跑团平台页面时，加入覆盖层的
身份完全由前端填写——知道他人的 ID（已注册官网用户名）即可
以其账号身份进入平台（查看其角色、以其名义发言、甚至抢注 DM
身份），全程无需登录。

修复（服务端校验，客户端无法绕过）：
- /api/room/join：声明的 ID 若为已注册官网用户名，必须由该账号
  本人登录（session 校验）后才能加入，否则拒绝并提示
  「该ID为已注册账号ID，请先登录该账号后进入」。
- /api/characters（PL 分支）：以已注册账号 ID 查询角色列表时同样
  校验登录身份，否则 403——防止伪造 sessionStorage 身份绕过
  加入覆盖层直接读取他人角色。
- character.js loadCharList：角色列表接口返回 error 时在列表区
  显示服务端错误信息（原先静默显示空列表）。

未登录的普通 ID（非注册用户名）仍可正常加入，不影响无账号的玩家。

验证（test_client）：
- 未登录 join「天冥」（已注册）→ 拒绝并返回明确提示 ✓
- 未登录 join 未注册 ID → 正常加入 ✓
- 未登录按「天冥」查角色列表 → 403 ✓
- 登录「天冥」后 join → 成功且保留 DM 身份 ✓
- 登录后角色列表 → 200 ✓

已知残留（另行规划）：角色增删改等按 id 操作的接口尚未做归属
校验，完整方案见优化方向文档「服务端房间鉴权」项。

2. 角色卡角色组默认折叠
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
问题：进入角色卡界面时全部分组默认展开，列表冗长。

修复：loadCharList 中分组 _collapsed 默认值改为 true，进入界面
时角色组默认关闭（点击组头展开）；总角色组保持展开不变。
