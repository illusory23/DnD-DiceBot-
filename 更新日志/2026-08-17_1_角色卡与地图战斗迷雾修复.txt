一、角色卡界面无法修改部分数据（属性/豁免）

（如"力量"），但 field_map 只认英文键，setattr 抛 AttributeError 被上层吞掉；
set_save_proficiency 同样以中文键查询/写入，与 create_character 存的英文键不一致，
导致豁免修改不生效并产生重复数据。后端返回 success 但 GET 读到的仍是旧值，
前端 selectChar 刷新后界面回退，表现为"无法修改"。
修复：
1. set_ability：中文属性名转回英文数据库列键后再 setattr。
2. set_save_proficiency：统一存英文键（与 create_character 一致），
   旧中文键数据自动迁移为英文键，不再产生重复行。

2. pushCombatState 的 WS 推送携带 _cid，1.5 秒内未收到 combat_update_ack
   自动降级 HTTP POST 兜底，保证服务器最终一致；ack 携带 _cid 回执。
3. 战斗轮询恢复为始终执行（WS 在线也轮询，作为 WS 半开时的兜底同步源）。
4. mapClearCombat 清空后置 started=false 并加 3 秒本地保护；
   applyRemoteCombatState 在本地刚清空（3 秒内）且服务器为非空旧状态时
   忽略服务器状态，防止"清空后回弹"。
5. combat.js 同步：clearCombat 清空推送（空状态带 _force）、轮询 3 秒

【补充：2026-08-17 修复】地图 token 旋转开始后无法停止
修改文件：web/static/map.js（map.html 版本号 v59→v60）

根因：
1. tokenNetData / textNetData 定义在 boot IIFE 内，但 addMapToken、拖拽、
   旋转 endRotate 等顶层代码引用它们 → ReferenceError。endRotate 里
   tokenNetData 抛错后，isRotating=false 与 rotToken=null 永远执行不到，
   旋转状态卡死，之后每次鼠标移动都继续转动 token，无法停止。
2. 旋转过程中 mouseup 丢失（鼠标拖出窗口/窗口失焦/触摸）时没有任何兜底，
   isRotating 同样卡住。
修复：
1. tokenNetData / textNetData 移到顶层作用域（顺带修复 token/文本框的
   WS 同步失败）。
2. endRotate 内 WS 推送加 try/catch，任何同步异常不再中断状态重置。
3. 新增旋转兜底：window mouseleave（鼠标离开窗口）、window blur（失焦）、
   地图任意 mousedown（点击他处）都会结束旋转。
4. 旋转手柄补 touch 支持（touchstart/touchmove/touchend），触屏也能
   拖拽旋转且松手必停止。
验证（真实事件模拟）：
- 正常 mousedown→mousemove→mouseup：旋转 270°，isRotating=false ✓
- mouseup 丢失（模拟鼠标拖出窗口）→ mouseleave 触发后旋转停止 ✓
- 窗口 blur → 旋转停止 ✓
- 旋转中途点击地图他处 → 旋转停止 ✓
