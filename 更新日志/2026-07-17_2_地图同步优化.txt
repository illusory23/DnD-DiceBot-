【P0-1 图片与状态分离 —— 流量降 95%+】
    - 地图底图不再以 base64 内嵌 JSON 传输/存储，
      改为落地 maps/layers/ 目录文件，状态只存 URL。
    - 新增上传端点 POST /api/shared-canvas/layer-image。
    - 启动时自动迁移旧数据: shared_canvas.json 1.8MB → 约2KB。
    - DM 推图消息从数 MB 降到约 200 字节，玩家按 URL 下载图片
      并走浏览器缓存。

【P0-3 线程安全】
    - shared_state.py 加模块级 RLock 保护全部读写，
      落盘前锁内深拷贝，多线程并发不再有数据竞争。
    - 压测: 10线程×20次并发写入, 0错误/0丢失/0重复。

【P1-1 版本号 + 操作语义 + 删除同步】
    - 服务端维护单调递增版本号，所有消息附带 _ver。
    - 新增 op 消息(单体增删改)，拖动一个 token 只广播这一个，
      不再全量广播；删除有了明确语义，不再出现"幽灵复活"。
    - 笔画带唯一 id，按 id 去重合并(替代旧的长度假设)。

【P1-2 通道整理】
    - WS 在线时为唯一通道，不再同时发 HTTP(旧版双份流量)。
    - HTTP 轮询 300ms → 1.5s，且未变化时服务端只回 71 字节。
    - 断线重连后自动发 sync 对账，版本落后自动补全量，
      离线期间他人的修改不再丢失。

【P1-3 拖拽保护 + 差量 DOM】
    - 收到远程更新时按 id 差量更新 DOM，不再删光重建。
    - 正在拖拽的对象受保护，不会被远程消息打断/弄丢。

【P2 杂项】
    - 防抖保存 + 15秒强制落盘兜底 + 退出时自动保存。
    - 主动清空立即落盘(重启后旧内容不再复活)。
    - WS 死连接发送失败即清理; 请求体上限 64MB。
    - debug=False(消除 Werkzeug 调试器远程执行风险)。
    - 删除无人调用的 /api/map-state 接口。

【使用者注意】
    - 启动方式不变: python dnd_bot.py --web
    - 首次启动会自动迁移旧画布数据并打印提示。
    - P0-2(服务端迷雾过滤)依赖鉴权体系，本次未实施。
