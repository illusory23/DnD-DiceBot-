2026-08-25_7_启动bat端口清理
═══════════════════════════════════════════

【背景】死亡豁免 404 排查发现：旧服务器进程（0:21 启动）一直残留
      监听 5000，与新进程并存，请求被分发到旧代码 → 新路由 404。
      关闭 bat 窗口对前台 python 通常有效但不保证（曾有残留实例）。

【修改】启动骰娘跑团平台官网.bat（GBK 编码，git 恢复后安全重建）：
  · :pyfound 标签后（启动横幅前）新增端口清理段：
      for /f "tokens=5" %%p in ('netstat -ano ^| findstr ":5000 "
        ^| findstr "LISTENING"') do (
          taskkill /F /PID %%p >nul 2>&1
      )
      timeout /t 2 /nobreak >nul
    —— 每次启动自动杀掉所有占用 5000 端口的残留进程（含旧代码
    实例），保证单实例运行、加载最新代码；2 秒等待端口释放

【实现注意】bat 为 GBK + LF 编码；第一次插入曾误匹配 goto :pyfound
      行尾部子串导致清理段落入 if 块内（且块内 goto 会跳过它），
      最终以独立行锚点（行首 :pyfound）重建插入；写入时 newline
      参数导致换行翻倍/丢失问题，最终统一以字节级读写修复。

【验证】
  · git 恢复原始版后重建，括号配平 OK（最终 0）
  · taskkill/timeout/python -m web.app 关键行全部确认
  · 总行数 53（原 45 + 清理段 8 行）

【生效】bat 下次启动即生效（无需重启服务器）；关闭窗口时前台
      python 随窗口退出，若仍有残留，下次启动自动清理
