【2026-08-14_3】迷雾线宽改为逐笔保存（不再跟随当前画笔粗细）

修改文件：
- web/static/map.js
- web/templates/map.html（仅缓存版本号 v=48 → v=49）

问题：
迷雾的渲染宽度和擦除判定一直使用全局 fogLineWidth()（跟随当前画笔粗细滑块）。
切换粗细度后：
- 之前画的粗雾会按新粗细重新渲染（粗雾变细/细雾变粗，显示变形）。
- 擦除判定范围也随粗细变化（粗细不同导致旧雾擦不干净或误擦）。

修复：
1. 每笔雾绘制时记录自己的线宽：fogStrokes 元素新增 width 字段（= 绘制当时的画笔粗细 ×3，最小 16px）。
2. 渲染：drawFogStrokeErased 用 fogStrokeWidth(stroke)（该笔自己的宽度），互不影响。
3. 擦除判定：eraserEffRadiusFor(stroke) = 擦除半径 + 该笔雾线宽一半——
   粗雾判定范围大、细雾判定范围小，各按自己的宽度被擦除。
4. 遮盖检测（isUnderFog）：探针判定用该笔雾自己的线宽。
5. 存档/同步：fogStrokes 序列化带 width 字段；旧存档无 width 自动退回当前默认宽度。

验证（9 项单元测试全过）：
- 粗雾(60px)/细雾(16px)/旧数据(默认16px) 宽度各自保持 ✓
- 擦除线距细雾 20px（eff=16）不擦、距粗雾 20px（eff=38）被擦 ✓
- 序列化往返 width 保持，旧存档兼容 ✓
