2026-08-09 更新 · 后台初始加载失败与事件统计修复
═══════════════════════════════════════════

一、问题：后台页面默认显示"加载失败"，点刷新才显示
───────────────────────────────────────────
• 根因：base.html 中 admin.js 在 <main> 之后（页面内联脚本之后）加载，
  页面内联脚本立即调用 Admin.get(...) 时 Admin 对象尚未定义 →
  ReferenceError → 初始加载全部中断（日志中初始 API 请求从未发出）
• 修复：admin.js 移到 <head> 中加载，内联脚本执行时 Admin 已就绪

二、问题：统计中心事件统计 400
───────────────────────────────────────────
• 根因：stats.html 调用 GET /api/events/stats（该接口必须带 name 参数，
  且返回结构是"用户事件内容统计"，与模板期望的"命令点击统计"不匹配）
• 修复：新增后台聚合接口 GET /admin/api/event-stats
  （按用户聚合 event_stats.json：总触发次数 + 各表事件明细），
  stats.html 改用新接口，展示：玩家 / 总触发 / 常用事件（前3）

三、服务器进程清理
───────────────────────────────────────────
• 检测到旧进程（03:27 启动）与新进程同时监听 5000 端口导致请求落到
  旧代码 → 全部杀掉后干净重启，线上验证全部 API 200

四、改动文件
───────────────────────────────────────────
• web/templates/admin/base.html（admin.js 移入 head）
• web/templates/admin/stats.html（事件统计改用 /admin/api/event-stats）
• web/admin.py（新增 GET /admin/api/event-stats 聚合接口）

五、线上验证（127.0.0.1:5000）
───────────────────────────────────────────
