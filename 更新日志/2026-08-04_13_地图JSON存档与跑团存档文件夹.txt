━━━ 服务端 API (web/app.py) ━━━
  GET    /api/map-saves         列出所有服务端地图存档
  POST   /api/map-saves         保存地图 JSON 到服务器
  GET    /api/map-saves/<name>  加载指定存档
  DELETE /api/map-saves/<name>  删除服务端存档

━━━ 前端功能 (map.js) ━━━
  📥 exportMapJSON()           一键下载 JSON 文件（含完整 base64 图层）
  📤 importMapJSON()           触发文件选择器导入
  🔄 handleMapJSONImport()     解析JSON → applyState() → 重建画布
  ☁️ saveMapToServer()         服务端保存（带名称输入）
  📂 loadMapFromServer()       服务端存档列表（展开式）
  📥 loadMapFromServerByName() 加载指定服务端存档
  🗑 deleteServerMapSave()     删除服务端存档
