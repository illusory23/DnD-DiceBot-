2026-08-31_9_回血攻击法术改为效果表驱动

需求（用户确认）：
回血类攻击法术（如吸血鬼之触）属于【攻击类型】——在攻击方式选择中
正常使用（攻击命中→掷伤害→扣目标血），"使用后自动回血"是【法术
效果】，与治疗机制无关：不进入治疗选择列表；攻击命中结算后按实际
伤害自动给施法者回血。实现采用"法术专属效果表"模式（用户指定：
为法术单独写效果函数，使用该法术时自动调用）。

实现（web/static/map.js，v86 → v87）：
1. isHealSpell 移除上轮加的"描述兜底"（回血攻击法术不再混入治疗列表），
   名称关键词扩充保留（复原/再生/医疗/愈合/活力/援助等纯治疗译名）
2. 新增法术专属攻击效果表：
   const SPELL_ATTACK_EFFECTS = { '吸血鬼之触': spellEffectVampiricTouch };
   —— 新法术效果在此登记即可（与北境 ITEM_USE_TABLE 同思路）
3. spellEffectVampiricTouch(dmg)：给攻击者（施法者）回复=实际伤害值
   的血量（HP API + 战斗列表同步 + token HP 刷新 + 聊天室播报
   "💚 xxx 使用 吸血鬼之触，恢复了 N 点血量（攻击伤害）"）
4. applySpellAttackEffect(dmg)：confirmDamage 确认结算伤害后调用的
   分发函数——命中法术在效果表中 → 自动调用对应效果函数；
   未登记的法术（火球术等）无任何副作用

验证（node test_heal_spell.mjs，21/21 通过，脚本已归档）：
- 治疗列表：复原术/次级复原术/再生术/医疗术/愈合真言/活力光环/
  援助术/治愈真言识别；吸血鬼之触不再进治疗列表；火球术不识别
- 效果表：吸血鬼之触命中 dmg=8 → 自动回血 8 + 播报；
  火球术（未登记）无效果；无攻击者/dmg=0 无效果
- node --check 语法通过；map.html v=87

涉及文件：
- web/static/map.js（v87）、web/templates/map.html（v=87）
