2026-08-31_3_掷骰帮助页演示修复与CLI删除导航后移

一、修复：演示掷骰全部按钮无效（web/templates/dice-help.html）
问题：
演示区预设按钮/输入后点"演示投掷"全部无反应。浏览器控制台报错：
dice-help:1 Uncaught TypeError: Failed to resolve module specifier
"cannon-es". Relative references must start with either "/", "./",
or "../".

根因：
dice-help.html 的 module script 直接 import DiceBox，但缺失
<script type="importmap"> 映射——dice-engine-v3/DiceBox.js 内部
`import from 'three'` / `from 'cannon-es'` 是裸模块名，浏览器无法
解析，导致整个 module 不执行，window.demoRoll / demoPreset 未定义，
页面内联 onclick 全部失效（dice3d-e.html 588 行有该 importmap，
新页面漏抄）。

修复：
- 在 module script 前补充与 dice3d-e.html 一致的 importmap：
  {"imports":{"three":"/static/three/three.module.min.js",
  "cannon-es":"/static/three/cannon-es.js"}}

二、删除：页面 CLI 部分（用户要求"CLI部分全部删除"）
- 删除「🖥️ CLI 掷骰指令」卡片区（.r/.check/.save/.ds/.init/.attack/
  .damage 等 9 张卡片）
- 删除「📚 其他 CLI 指令」折叠区（.char/.ss/长休短休/资料查询/
  事件表/系统）
- 同步删除 .cmd-grid/.cmd-card/details.collapse/code.cmd 相关 CSS
- 页面保留：🎲 演示掷骰 + ✏️ 掷骰表达式语法

  reference / mods / events / index / dice-help 自身
