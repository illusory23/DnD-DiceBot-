战斗轮界面（地图内嵌战斗面板 + 独立战斗页 combat.html）
原先对所有观看者显示全部参战者的具体血量。现按身份脱敏：

- DM 视角：全部战斗者显示真实血量（原有绿/金/红血量颜色保留）；
- PL 视角：仅「自己的角色」与「DM 公开角色（is_public）」显示
  真实血量，其余战斗者显示「❤️ ?/? · 状态文字」；
- 状态文字按血量比例划分五档（对可见与不可见者均适用）：
    毫发无损（满血）
    轻伤（2/3 < HP < 满）
    中等伤势（1/3 < HP ≤ 2/3）
    重伤（0 < HP ≤ 1/3）
    死亡（HP ≤ 0）
  不可见时状态文字按对应档位着色（绿/绿/金/红/红），死亡档
  显示为红色「死亡」。

实现要点：
- 新增 hpStatusOf(hp, hpMax) 五档状态函数（map.js 与 combat.js
  各自一份，与两文件独立作用域风格一致）；
- 可见性判定：map.js 复用 canViewCharInfo（is_public /
  created_by / 角色名=玩家名，与 token 信息面板同口径）；
  combat.js 新增 canViewCombatantHp（DM 全可见；PL 自己添加的
  战斗者可见 + charCache 中公开角色/自己创建/同名角色可见）；
- 角色数据补拉：战斗者未缓存角色数据时异步拉取
  /api/character/<id> 后重渲染，失败（私有角色）标记后不再
  重复请求，防止循环拉取；
- 伤害/治疗目标下拉框选项同步脱敏：不可见者显示
  「名字 (❤️?/?)」，选中值不受影响；
- 手动输入伤害/治疗数值的结算弹窗仅 DM 操作者可见，PL 只读
  战斗面板，alert 中的真实血量不涉及 PL。

验证：
- node --check map.js / combat.js 语法通过；
- 权限口径与既有 token 隐私（canViewCharInfo）一致。
