一、修复
───────────────────────────────────────────
• 修复：双击「启动骰娘跑团平台官网.bat」后命令行窗口闪退问题
• 原因 1：原 bat 为 UTF-8 编码 + chcp 65001 切换代码页，部分系统上 cmd
  解析异常，可能导致窗口异常退出
• 原因 2：原 bat 用 `start cmd /c "timeout..."` 弹出辅助窗口，该窗口
  4 秒后自动关闭，观感上像「跳出来又自动关闭」，易误判为启动失败

二、改动文件
───────────────────────────────────────────
• 启动骰娘跑团平台官网.bat（重写）

三、增强
───────────────────────────────────────────
• bat 改为 GBK 编码 + CRLF 换行（cmd 原生格式），去除 chcp 65001
• 浏览器自动打开改为后台延时执行（start /b powershell），不再弹出辅助窗口，
  双击后只保留一个服务器主窗口
• 新增 Python 命令探测兜底：where python 失败时回退
  %LOCALAPPDATA%\Programs\Python\Python313\python.exe（含 Python312），
  完全找不到时显示提示并停留窗口
• 新增失败提示：端口被占用或启动出错时显示原因（如端口 5000 被占用、
  依赖缺失可运行 pip install -r requirements.txt）

四、验证
───────────────────────────────────────────
模拟双击完整流程：服务器启动成功，官网首页返回 200

五、使用注意
───────────────────────────────────────────
• 双击后只有一个黑色窗口常驻（显示服务器日志），关闭它即停止服务
