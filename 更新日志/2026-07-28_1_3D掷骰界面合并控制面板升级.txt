一、改动概述
──────────────────────────────────────────────────────────────────────

核心原则：不改动3D渲染/物理引擎/WebSocket同步 → 只升级控制面板UI
改动范围：dice3d-e.html 完全重写控制栏 + 9个模板的导航栏同步更新
备份文件：dice3d-e-backup-20260728.html（可回滚）

二、dice3d-e.html 改造详情
──────────────────────────────────────────────────────────────────────

【控制栏升级】从原来的单行简易栏升级为三行完整构建器：

  第一行：骰子类型(d4-d100) + 模式(正常/优势/劣势) + 💥爆炸骰 + 保留/丢弃
  第二行：个数步进器 + 加值步进器 + 快捷预设(3d6/4d6k3/2d6+3/8d6等)
  第三行：自定义表达式输入 + 桌布选择 + 自定义上传 + [🎲投掷！]

【新增功能】
  - 💥 爆炸骰开关（投出最大值再投一次）
  - 保留/丢弃选择器（kh/kl/dh/dl + 数量）
  - 8个快捷预设按钮（含d20优势/劣势）
  - 自定义表达式输入框（支持回车掷骰）
  - 🔗 联机同步开关（可切换在线/离线模式）
  - 禁用状态的投掷按钮样式

【核心逻辑改造】doRoll() 改为 API 驱动模式：
  原逻辑：前端 Math.random() 生成值 → 构建 detNotation → 播放动画
  新逻辑：构建表达式 → 调用 /api/roll → 用结果构建 detNotation → 播放动画

  优势：
  - 后端 dice_engine 已完美支持 k/d/!/adv/dis 全部语法
  - 前端无需实现复杂骰子逻辑
  - API 结果通过 WebSocket 广播给联机玩家
  - 兼容旧版确定性骰子消息格式（dice_roll_det）

【3D核心完全不动】
  - DiceBox 初始化、物理参数、材质主题 → 不变
  - 桌布切换（12种预设+自定义上传） → 不变
  - WebSocket 连接/同步逻辑 → 不变
  - 结果显示 overlay → 不变
  - 骰子颜色分配（多人区分） → 不变

三、index.html 改造详情
──────────────────────────────────────────────────────────────────────

  - 属性生成面板（4d6k3/3d6/购点法）
