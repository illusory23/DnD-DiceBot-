一、新增
───────────────────────────────────────────
• 新增「启动骰娘跑团平台官网.bat」（位于骰娘根目录），双击即可一键启动官网
• 启动方式：cd 骰娘根目录后 `python -m web.app`（端口 5000）
• 启动成功后约 4 秒自动打开浏览器进入官网门户 http://localhost:5000/
• 关闭命令行窗口即停止服务

───────────────────────────────────────────
• 启动骰娘跑团平台官网.bat（新增）

三、使用注意
───────────────────────────────────────────
• 不能用 `cd web && python app.py` 直接启动：web/app.py 模块加载时有相对导入
  （from .shared_state import ...），必须从骰娘根目录以包方式运行
  （python -m web.app 或 python dnd_bot.py --web）
• README「快速开始」中的启动写法与实际代码不符（会报 ImportError），
  以及官网门户路径 /portal/ 已过时（实际为 /，渲染 portal/index.html），
  建议后续修正 README
