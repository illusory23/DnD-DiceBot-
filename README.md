## 1. 项目概述

尘封之卷是一个面向 D&D 5E 规则的线上跑团辅助平台，提供三大核心体验：

- **跑团工具平台**：3D 掷骰、角色卡管理、战斗追踪、法术/怪物查询、聊天室
- **官网门户**：项目展示、用户系统、功能导航、视频背景
- **北境雪原**：基于"九子的注视"世界观的探索生存玩法，可独立运行

## 3. 技术架构

| 层级 | 技术栈 |
|------|--------|
| **后端** | Python 3 + Flask |
| | `web/app.py` — Flask 主应用，路由注册 |
| | `web/admin.py` — 管理员后台 Blueprint（/admin/*） |
| | `core/` — 核心引擎（骰子、角色、D&D 规则） |
| | `utils/` — 工具（数据加载、CHM 搜索、Excel 导入、日志） |
| | `dnd_bot.py` — QQ 机器人指令适配 + 事件表定义 |
| **前端** | 原生 HTML/CSS/JS（无框架依赖） |
| | 3D 掷骰 — @3d-dice/dice-box (Three.js 物理引擎) |
| | 确定性骰子引擎 — 自定义 Three.js 同步骰子系统 |
| | 雪地特效 — Canvas 雪花 + 极光粒子 |
| | 在线心跳 — `online-presence.js` 全站在线状态 |
| | 事件驱动 — 原生事件委托 |
| **数据** | PostgreSQL — 32 张表（2026-08-15 全量迁移，DATABASE_URL 可覆盖） |
| | JSON — 法术库、怪物库、物品表（只读资料） |
| | CHM 索引 — 离线 D&D 规则检索 |
| | TXT — 随机事件表定义 |
| **安全** | 用户名白名单校验、密码哈希、SECRET_KEY 随机持久化、审计日志 |

## 5. 快速开始

### 5.1 环境要求

- Python 3.8+
- pip

### 5.2 安装依赖

```bash
cd 骰娘
pip install -r requirements.txt
```

### 5.3 启动服务

```bash
cd 骰娘/web
python app.py
```

默认访问地址：`http://localhost:5000`

## 9. 事件表系统

事件表定义在**三处**保持同步：

1. `web/static/north-data.js` — JavaScript `TABLES` 对象（`window.NORTH_DATA`，前端渲染用）
2. `dnd_bot.py` — Python 字典（QQ 机器人用）
3. `data/随机事件表.txt` — 文字版参考文档

### 链式调用机制

```
顶层表 → 子表 → 叶子表（产生实际效果）
如：全随机(qsj100) → 探索(ts100) → 采集资源 → 材料(cl50) → 获取物品
```

### 效果触发层级

| 类型 | 说明 |
|------|------|
| `ITEM_ACTIONS` | 自动拾取（材料/矿物表） |
| `CHECK_ACTIONS` | 检定交互（DC 检定 + 3D 掷骰按钮） |
| `LINK_RULES` | 联动规则（猎人小屋/温泉/岩洞等） |
| 敌对战斗/逃离按钮 | 野兽/敌对生物遭遇 |
| 喂食交互 | 友善生物 |

## 10. 开发指南

### 10.1 添加新事件表条目

1. 在 `web/static/north-data.js` 的 `TABLES` 对象中添加条目
2. 如需检定交互，在 `CHECK_ACTIONS` 中添加 `steps` 定义
3. 如需自动拾取，在 `ITEM_ACTIONS` 中添加 `ranges`
4. 同步更新 `dnd_bot.py` 中的对应 Python 字典
5. 同步更新 `data/随机事件表.txt`

### 10.2 CHECK_ACTIONS step 格式

```javascript
{
  label:    '步骤标签',        // 必填
  ability:  'str|dex|con|int|wis|cha', // 属性
  skill:    '技能名',          // 可选，技能检定
  save:     true,              // 可选，豁免检定
  passive:  true,              // 可选，被动检定(d20=10)
  dc:       15,                // DC 值
  damage:   '1d6',             // 可选，失败伤害
  passMsg:  '通过消息',
  failMsg:  '失败消息',
  passDone: true,              // 通过后结束检定
  failDone: true,              // 失败后结束检定
  passEffect: fn,              // 可选，通过后执行
  failEffect: fn,              // 可选，失败后执行
  failExtra: {...}             // 可选，失败后额外步骤
}
```

### 10.3 3D 骰子集成

`dice-bridge.js` 提供 `window.roll3DDice(notation)` 接口：
- 支持玩家取消 → 回退为文本掷骰
- 自动降级：3D 不可用时使用随机数
