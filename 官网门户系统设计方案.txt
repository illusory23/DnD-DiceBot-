━━━ 一、系统概述 ━━━

目标: 为骰娘D&D跑团平台构建一个完整的官网门户系统，提供:
  - 用户注册/登录/账户管理
  - 平台功能展示与引导
  - 内置社区（论坛/聊天/帖子）
  - 创意工坊（扩展/模组/资源投稿与分享）

架构: 基于现有 Flask 单文件架构扩展为模块化蓝图(Blueprint)架构，
       新增SQLite数据库（后期可迁移到PostgreSQL），
       前端使用原生 HTML/CSS/JS（保持与现有页面风格一致）。


━━━ 二、技术栈选型 ━━━

 后端:
   Web框架:    Flask（现有，扩展蓝图）
   数据库:     SQLite（开发期）→ PostgreSQL（生产期）
   ORM:        Flask-SQLAlchemy
   认证:       Flask-Login + bcrypt 密码哈希
   会话管理:   Flask-Session（服务端session，Redis可选）
   文件上传:   Flask-Uploads（头像/附件）
   邮件:       Flask-Mail（注册验证/密码重置）
   搜索:       Whoosh（社区帖子全文搜索）

 前端:
   页面渲染:   Jinja2 模板（现有）
   样式:       原生 CSS（现有 style.css + 扩展）
   交互:       原生 JavaScript（现有风格）
   富文本:     Quill.js（帖子编辑器，CDN引入）
   文件上传:   Dropzone.js（创意工坊上传，可选CDN）

 部署:
   现有:       Flask 内置服务器 (开发)
   推荐:       Gunicorn + Nginx (生产)
   容器化:     Docker + Docker Compose

━━━ 四、数据库设计 ━━━

核心表结构（SQLite，后期迁移PostgreSQL）:

-- 用户表
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username VARCHAR(64) UNIQUE NOT NULL,
    email VARCHAR(128) UNIQUE NOT NULL,
    password_hash VARCHAR(256) NOT NULL,
    avatar_url VARCHAR(512),
    bio TEXT,
    role VARCHAR(16) DEFAULT 'user',  -- user | moderator | admin
    is_active BOOLEAN DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login TIMESTAMP,
    email_verified BOOLEAN DEFAULT 0
);

-- 密码重置令牌
CREATE TABLE password_reset_tokens (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL REFERENCES users(id),
    token VARCHAR(128) UNIQUE NOT NULL,
    expires_at TIMESTAMP NOT NULL,
    used BOOLEAN DEFAULT 0
);

-- 社区板块
CREATE TABLE boards (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(64) NOT NULL,
    slug VARCHAR(64) UNIQUE NOT NULL,
    description TEXT,
    sort_order INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT 1
);

-- 帖子
CREATE TABLE posts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    board_id INTEGER NOT NULL REFERENCES boards(id),
    user_id INTEGER NOT NULL REFERENCES users(id),
    title VARCHAR(256) NOT NULL,
    content TEXT NOT NULL,          -- HTML (Quill.js输出)
    content_raw TEXT,               -- 原始 Markdown
    tags VARCHAR(256),              -- 逗号分隔标签
    is_pinned BOOLEAN DEFAULT 0,
    is_locked BOOLEAN DEFAULT 0,
    view_count INTEGER DEFAULT 0,
    like_count INTEGER DEFAULT 0,
    reply_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_reply_at TIMESTAMP
);

-- 回复
CREATE TABLE replies (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    post_id INTEGER NOT NULL REFERENCES posts(id),
    user_id INTEGER NOT NULL REFERENCES users(id),
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 点赞
CREATE TABLE likes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL REFERENCES users(id),
    target_type VARCHAR(16) NOT NULL,  -- 'post' | 'reply' | 'workshop_item'
    target_id INTEGER NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, target_type, target_id)
);

-- 创意工坊项目
CREATE TABLE workshop_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL REFERENCES users(id),
    title VARCHAR(256) NOT NULL,
    category VARCHAR(32) NOT NULL,   -- extension | map_pack | template | monster | dice_skin | tool
    description TEXT NOT NULL,
    install_guide TEXT,
    tags VARCHAR(256),
    version VARCHAR(32) DEFAULT '1.0.0',
    download_count INTEGER DEFAULT 0,
    rating_avg FLOAT DEFAULT 0,
    rating_count INTEGER DEFAULT 0,
    is_published BOOLEAN DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 工坊文件
CREATE TABLE workshop_files (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    item_id INTEGER NOT NULL REFERENCES workshop_items(id),
    filename VARCHAR(256) NOT NULL,
    file_path VARCHAR(512) NOT NULL,
    file_size INTEGER,
    version VARCHAR(32),
    download_count INTEGER DEFAULT 0,
    is_current BOOLEAN DEFAULT 1,
    uploaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 工坊预览图
CREATE TABLE workshop_images (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    item_id INTEGER NOT NULL REFERENCES workshop_items(id),
    image_path VARCHAR(512) NOT NULL,
    sort_order INTEGER DEFAULT 0
);

-- 工坊评分
CREATE TABLE workshop_ratings (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    item_id INTEGER NOT NULL REFERENCES workshop_items(id),
    user_id INTEGER NOT NULL REFERENCES users(id),
    rating INTEGER NOT NULL CHECK(rating BETWEEN 1 AND 5),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(item_id, user_id)
);

-- 通知
CREATE TABLE notifications (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL REFERENCES users(id),
    type VARCHAR(32) NOT NULL,      -- reply | mention | like | workshop_comment
    content TEXT NOT NULL,
    link VARCHAR(512),
    is_read BOOLEAN DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 平台统计
CREATE TABLE site_stats (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    stat_key VARCHAR(64) UNIQUE NOT NULL,
    stat_value INTEGER DEFAULT 0,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

━━━ 六、API 路由设计 ━━━

6.1 认证相关 (/account)
  GET  /account/login             → 登录页面
  POST /account/login             → 登录处理
  GET  /account/register          → 注册页面
  POST /account/register          → 注册处理
  GET  /account/logout            → 退出登录
  GET  /account/profile/<user>    → 用户主页
  GET  /account/settings          → 账户设置
  POST /account/settings          → 保存设置
  POST /account/upload-avatar     → 上传头像
  GET  /account/reset-password    → 密码重置页
  POST /account/reset-password    → 发送重置邮件
  GET  /account/reset/<token>     → 重置密码（令牌验证）
  POST /account/reset/<token>     → 设置新密码

6.2 社区相关 (/community)
  GET  /community                 → 社区首页（板块+热帖）
  GET  /community/board/<slug>    → 板块帖子列表
  GET  /community/post/<id>       → 帖子详情
  POST /community/post/<id>/reply → 发表回复
  GET  /community/new             → 发帖页面
  POST /community/new             → 创建帖子
  POST /community/post/<id>/like  → 点赞
  GET  /community/search          → 搜索帖子

6.3 创意工坊 (/workshop)
  GET  /workshop                  → 工坊首页
  GET  /workshop/item/<id>        → 项目详情
  GET  /workshop/submit           → 投稿页面
  POST /workshop/submit           → 提交投稿
  GET  /workshop/my               → 我的工坊
  POST /workshop/item/<id>/rate   → 评分
  POST /workshop/item/<id>/comment → 评论
  GET  /workshop/item/<id>/download → 下载文件
  POST /workshop/item/<id>/edit   → 编辑投稿
  POST /workshop/item/<id>/delete → 删除投稿

6.4 开放 API (/api/v1)
  GET  /api/v1/workshop/items     → 工坊项目列表
  GET  /api/v1/workshop/search    → 搜索工坊
  GET  /api/v1/stats              → 平台统计数据
  GET  /api/v1/community/posts    → 社区帖子列表

━━━ 八、安全注意事项 ━━━

8.1 认证安全
    - 密码: bcrypt 哈希（work factor ≥ 12）
    - Session: Flask-Login + HttpOnly Cookie + Secure标志
    - 登录限流: 5次失败 → 15分钟冷却（Flask-Limiter）
    - 注册验证码: 简单数学题（开发期）/ reCAPTCHA（生产期）

8.2 输入安全
    - XSS防护: 富文本内容 Bleach 白名单过滤
    - SQL注入: SQLAlchemy ORM 参数化查询（自动防护）
    - CSRF: Flask-WTF CSRF token（所有POST表单）
    - 文件上传: 扩展名白名单 + 文件头魔数验证 + 大小限制

8.3 数据安全
    - 敏感配置（SECRET_KEY等）使用环境变量
    - 数据库文件放在 web 目录外（防直接下载）
    - 用户上传文件使用随机文件名（防路径遍历）
    - 定期备份（见第6.4节）

8.4 隐私
    - 邮箱仅在密码重置时使用
    - 用户可设置个人主页公开/私密
    - IP地址不公开显示
    - 遵守数据删除请求（GDPR基础合规）

    from werkzeug.security import generate_password_hash, check_password_hash

    class User(UserMixin, db.Model):
        __tablename__ = 'users'

        username = db.Column(db.String(64), unique=True, nullable=False)
        email = db.Column(db.String(128), unique=True, nullable=False)
        password_hash = db.Column(db.String(256), nullable=False)
        # ... 其他字段

            self.password_hash = generate_password_hash(password)

9.3 社区蓝图示例 (blueprints/community.py):

    from flask import Blueprint, render_template, request, redirect, url_for
    from flask_login import login_required, current_user
    from models import Board, Post, Reply, db

    community_bp = Blueprint('community', __name__, url_prefix='/community')

    @community_bp.route('/')
    def index():
        boards = Board.query.filter_by(is_active=True).order_by(Board.sort_order).all()
        recent_posts = Post.query.order_by(Post.last_reply_at.desc()).limit(20).all()
        return render_template('community/index.html', boards=boards, recent_posts=recent_posts)

    @community_bp.route('/board/<slug>')
    def board(slug):
        board = Board.query.filter_by(slug=slug).first_or_404()
        page = request.args.get('page', 1, type=int)
        posts = Post.query.filter_by(board_id=board.id)\
            .order_by(Post.is_pinned.desc(), Post.last_reply_at.desc())\
            .paginate(page=page, per_page=20)
        return render_template('community/board.html', board=board, posts=posts)

    @community_bp.route('/post/<int:post_id>', methods=['GET', 'POST'])
    def view_post(post_id):
        post = Post.query.get_or_404(post_id)
        post.view_count += 1
        db.session.commit()
        if request.method == 'POST' and current_user.is_authenticated:
            content = request.form.get('content', '').strip()
            if content:
                reply = Reply(post_id=post.id, user_id=current_user.id, content=content)
                db.session.add(reply)
                post.reply_count += 1
                post.last_reply_at = db.func.now()
                db.session.commit()
        replies = Reply.query.filter_by(post_id=post.id)\
            .order_by(Reply.created_at.asc()).all()
        return render_template('community/post.html', post=post, replies=replies)

━━━ 十一、部署选项建议 ━━━

 方案A: 内网使用（当前模式）
    - Flask 内置服务器运行，仅局域网访问
    - SQLite 数据库（够用）
    - 不需要邮件系统（管理员手动激活账户）
    - 预计工时: 4-6周（单人开发）

 方案B: 公网部署（推荐）
    - 云服务器 (阿里云/腾讯云 2核4G)
    - Nginx + Gunicorn + PostgreSQL
    - 域名 + HTTPS (Let's Encrypt)
    - 邮件服务 (阿里云邮件推送)
    - 预计工时: 6-8周（单人开发 + 部署调试）

 方案C: Docker 容器化（最佳实践）
    - Docker Compose: Flask + PostgreSQL + Nginx + Redis
    - 一键部署脚本
    - 自动备份 + 日志轮转
    - 预计工时: 8-10周（单人开发 + Docker配置）

本方案设计了一个完整的跑团平台门户系统，包含用户系统、社区论坛、
