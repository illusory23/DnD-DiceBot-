🎲 DND5E 骰娘 v2.1 — 功能总结
═══════════════════════════════════════════════════════════════

启动方式
───────────────────────────────────────────────────────────────
  python dnd_bot.py              交互模式 (命令行)
  python dnd_bot.py ".r 3d6"     单次命令模式
  python dnd_bot.py --web        Web 模式 (浏览器访问 localhost:5000)

  服务器端口：5000（HTTP + WebSocket 共用，FRP 单端口兼容）
  WebSocket 路径：/ws（Flask-Sock，与 HTTP 同端口）

Web 模式页面导航：
  /             掷骰面板
  /map          战术地图 ★核心协作功能
  /character    角色卡编辑
  /combat       战斗追踪器
  /spells       法术管理
  /events       随机事件表
  /reference    资料库搜索
  /chat         聊天室

命令前缀容错：输入 3d6 自动转为 .r 3d6，adv d20 自动转为 .r adv d20

📌 CLI 命令行功能
═══════════════════════════════════════════════════════════════

🎲 掷骰
───────────────────────────────────────────────────────────────
  .r <表达式>              通用掷骰 (3d6 / d20+5 / 4d6k3)
  .r adv <表达式>          优势掷骰 (2d20取高)
  .r dis <表达式>          劣势掷骰 (2d20取低)
  .dnd [数量]              随机属性生成 (4d6k3，可一次多组)


🎯 检定
───────────────────────────────────────────────────────────────
  .check <属性/技能> [优势/劣势]   属性或技能检定
  .save <属性> [优势/劣势]         豁免检定
  .ds                               死亡豁免


⚔️ 战斗
───────────────────────────────────────────────────────────────
  .init <+加值> <名字>    掷先攻并加入列表
  .init list              查看先攻顺序
  .init start             开始战斗 (第1轮)
  .init next              切换到下一回合
  .init remove <名字>     移除参战者
  .init clear             清空先攻列表
  .attack <武器> [-t 目标] [优势/劣势]   攻击检定
  .damage <表达式>                       伤害投掷


👤 角色卡管理 (.char)
───────────────────────────────────────────────────────────────
  .char new <名字>                创建新角色
  .char import <Excel文件>        从 Excel 人物卡导入角色
  .char show [-d] [名字]          查看角色卡
  .char use <名字>                选择当前活跃角色
  .char list                      列出所有角色
  .char delete <名字>             删除角色

  属性设置：.char set STR 16 / .char set 察觉 熟练
  生命值：  .char hp / .char hp +5 / .char hp set <值>
  武器装备：.char weapon add <名> <命中> <伤害> [描述] [效果]
  钱币：    .char coin / .char coin add gp 10
  物品：    .char item add <名> [x数量] [描述] [效果]
  法术：    .char spell add <法术名> [环数]
  背景：    .char bg / .char bg set <字段> <内容>
  头像：    .char portrait <文件路径> / clear / open


✨ 法术位 (.ss)
───────────────────────────────────────────────────────────────
  .ss init / .ss use <环数> / .ss restore [环数]


🛌 休整
───────────────────────────────────────────────────────────────
  .longrest              长休：恢复全部HP/法术位/生命骰
  .shortrest [骰数]      短休：消耗生命骰恢复HP

🌐 Web 界面功能

🔐 身份系统（DM / PL）
───────────────────────────────────────────────────────────────

  【加入房间】
    打开任何页面 → 加入覆盖层 → 输入ID / 选择颜色 / 选择身份
    ┌─────────────────────────────────────────────────────────┐
    │ 👑 DM（主持人）  → 地图编辑 / 迷雾 / 清除 / 战斗管理  │
    │ 🎭 PL（玩家）    → 只读战斗 / 不可迷雾 / 不可清除     │
    └─────────────────────────────────────────────────────────┘

  【身份锁定】
    加入时选择的身份在本次会话永久锁定。
    切换页面 / 刷新浏览器 不会改变身份。
    重新打开浏览器并加入房间才能更换身份。

  【ID 唯一性】
    同一 ID 不可被多人同时使用。
    刷新页面时同 IP 自动放行（不会锁定自己）。
    10 秒无心跳自动清理离线用户。

  【在线检测】
    心跳间隔：3 秒（快速检测在线状态）
    离线超时：10 秒无心跳


🗺️ 战术地图 (/map) ★核心协作功能
───────────────────────────────────────────────────────────────

  【实时同步（自动，无需手动操作）】
    · 所有用户进入地图页面后自动连接共享画布
    · DM/PL 的涂画、标记、文字操作实时广播给所有在线用户
    · 图层变更自动推送
    · WebSocket（/ws）+ HTTP 轮询双通道

  【手动同步（备用）】
    · DM 📤 推送按钮：全量写入服务端（含地图图层 dataURL）
    · PL 🔄 同步按钮：全量拉取服务端共享画布

  【工具栏（双行可折叠）】
    第一行：选择 | 画笔 | 橡皮 | 填充 | 迷雾 | 文字 | 颜色 | 大小
           导入 | 地图 | 资源库 | 存档 | 图层 | 适应 | 重置 | 锁定 | 缩放
    第二行：导航链接（掷骰/角色卡/战斗/法术/事件/参考/聊天室）

  【图层系统】
    · 导入多张地图图片作为图层
    · 独立控制：显示/隐藏、缩放、移动、重命名、删除
    · 图层 dataURL 存储在服务端，PL 通过单独 URL 加载（减小 JSON 体积）

  【绘图工具】
    · ✏️ 画笔：自由绘制，可调颜色 (色轮) 和大小 (1-1000px)
    · 🧹 橡皮：擦除涂画
    · 🪣 填充：区域洪水填充
    · 🔤 文字：点击放置文字框，双击编辑
    · 快捷键：V选择 B画笔 E橡皮 F填充 G迷雾 T文字

  【战争迷雾】
    DM 视角：半透明深灰，可看到下方内容
    PL 视角：完全不透明实心灰色（无法看到下方任何内容）
    PL 不可使用迷雾绘制/删除功能（按钮隐藏 + 代码级阻止）

  【角色标记】
    · 从侧边栏拖拽角色到地图（圆形头像标记）
    · 拖拽移动、调整大小、旋转
    · 选中后左侧弹出角色信息面板
    · 双击删除标记

  【PL 功能限制】
    · 不可使用：战争迷雾 / 清除涂画 / 全部清除
    · 迷雾区域完全不透明
    · 战斗面板只读
    · 按钮被隐藏 + 代码级阻止（双重保障）

  【存档系统】
    · 多存档槽位（命名、切换、覆盖、重命名、删除）
    · IndexedDB 存储（支持大体积地图图片）
    · 自动保存（每 3 秒）
    · 页面离开时立即保存
    · 刷新页面自动恢复

  【底部骰子栏】
    表达式输入 | 优势/劣势/正常 | d20/优势/劣势/d6/d8/3d6/4d6k3/察觉/隐匿

  【左侧聊天面板】
    实时聊天 | 在线用户列表 | ID 颜色选择 | @提及通知

🔄 共享画布技术架构
═══════════════════════════════════════════════════════════════

  【同步通道】
    · 主通道：WebSocket (/ws, 端口 5000) — 实时增量广播
    · 备用通道：HTTP 轮询 (/api/shared-canvas) — 300ms 增量拉取
    · 手动通道：📤 推送 / 🔄 同步按钮 — 全量写入/读取

  【服务端存储】
    · 内存：shared_state 模块（笔画/图层/标记/文字/迷雾）
    · 磁盘：web/shared_canvas.json（3 秒防抖自动保存）
    · 启动时自动从磁盘恢复

  【图层图片优化】
    · 同步响应的 JSON 不包含 dataURL（仅元数据）
    · 图层图片通过 /api/shared-canvas/layer/<id> 端点单独加载
    · 避免大体积 JSON 导致 FRP 传输超时

  【增量同步】
    · 笔画：每笔单独追加（不发送全部历史）
    · 标记/文字：按 id 增量合并
    · 图层：元数据增量，图片按需加载
    · 迷雾：全量替换

🌐 公网访问（FRP 内网穿透）
═══════════════════════════════════════════════════════════════

  【单端口部署】
    仅需穿透端口 5000（HTTP + WebSocket 共用）
    WS 路径：/ws（frp 自动转发 WebSocket 升级请求）

  【角色检测适配】
    frp 环境下所有用户 IP 显示为 127.0.0.1
    身份判定以用户加入时选择的 DM/PL 为准（不依赖 IP）
    多人共享 IP 时自动禁用 IP 检测

  【推荐工具】
    · ZeroTier（虚拟局域网，推荐）
    · 樱花 FRP（内网穿透，仅需一个端口）
    · ngrok（临时测试）
