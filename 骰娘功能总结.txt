启动方式
───────────────────────────────────────────────────────────────
  python dnd_bot.py              交互模式 (命令行)
  python dnd_bot.py ".r 3d6"     单次命令模式
  python dnd_bot.py --web        Web 模式 (浏览器访问 localhost:5000)

Web 模式页面导航：
  /             掷骰面板
  /map          战术地图 ★核心功能
  /character    角色卡编辑
  /combat       战斗追踪器
  /spells       法术管理
  /events       随机事件表
  /reference    资料库搜索

命令前缀容错：输入 3d6 自动转为 .r 3d6，adv d20 自动转为 .r adv d20

📌 CLI 命令行功能
═══════════════════════════════════════════════════════════════

🎲 掷骰
───────────────────────────────────────────────────────────────
  .r <表达式>              通用掷骰 (3d6 / d20+5 / 4d6k3)
  .r adv <表达式>          优势掷骰 (2d20取高)
  .r dis <表达式>          劣势掷骰 (2d20取低)
  .dnd [数量]              随机属性生成 (4d6k3，可一次多组)


🎯 检定
───────────────────────────────────────────────────────────────
  .check <属性/技能> [优势/劣势]   属性或技能检定，自动使用角色属性值和熟练加值
  .save <属性> [优势/劣势]         豁免检定，自动计算角色豁免熟练
  .ds                               死亡豁免，追踪成功/失败/稳定


⚔️ 战斗
───────────────────────────────────────────────────────────────
  .init <+加值> <名字>    掷先攻并加入列表
  .init add +3 哥布林     另一种添加方式
  .init list              查看先攻顺序
  .init start             开始战斗 (第1轮)
  .init next              切换到下一回合
  .init remove <名字>     移除参战者
  .init clear             清空先攻列表
  .attack <武器> [-t 目标] [优势/劣势]   攻击检定，自动匹配角色武器库命中加值
  .damage <表达式>                       伤害投掷，如 .damage 2d6+3


👤 角色卡管理 (.char)
───────────────────────────────────────────────────────────────
基本操作：
  .char new <名字>                创建新角色
  .char import <Excel文件>        从 Excel 人物卡导入角色
  .char show [-d] [名字]          查看角色卡，-d 显示完整详情
  .char use <名字>                选择当前活跃角色
  .char list                      列出所有角色
  .char delete <名字>             删除角色
  .char open                      打开导入的角色卡源文件

属性与技能设置 (.char set)：
  .char set STR 16                设置力量为16
  .char set 察觉 熟练             设置技能熟练度 (熟练/专精/非熟练)
  .char set 力量 豁免 熟练        设置豁免熟练
  .char set 职业 战士             设置基础信息 (职业/种族/阵营/信仰/等级/玩家/性别/年龄/身高/体重)

生命值 (.char hp)：
  .char hp                        查看当前HP (含临时HP)
  .char hp +5 / -10               相对调整HP
  .char hp set <值> [最大值]      设置当前HP，可同时设最大HP
  .char hp max <值>               单独设置最大HP

武器装备 (.char weapon)：
  .char weapon                    查看武器列表
  .char weapon add <名> <命中> <伤害> [类型] [描述:] [效果:]   添加武器
  .char weapon remove <ID/名称>   删除武器
  .char weapon clear / list       清空/列出武器

钱币 (.char coin)：
  .char coin                      查看钱币 (cp/sp/ep/gp/pp)
  .char coin add <币种> <数量>    增减钱币
  .char coin set cp sp ep gp pp   一次性设置所有币种

物品 (.char item)：
  .char item                      查看物品栏
  .char item add <名> [x数量] [重量] [@位置] [描述:] [效果:]   添加物品
  .char item remove <ID/名称> [数量]   删除或减少物品
  .char item set <ID> <数量>           设置物品数量 (≤0则删除)
  .char item stack                     合并同名重复物品
  .char item clear                     清空物品栏

法术准备 (.char spell)：
  .char spell                     查看已准备法术
  .char spell add <法术名> [环数] 添加已准备法术
  .char spell clear               清空法术列表

背景 (.char bg)：
  .char bg                        查看全部背景信息
  .char bg set <字段> <内容>      设置：个性/理念/羁绊/缺陷/背景特性/外貌/出身/语言/熟练工具/背景故事

头像 (.char portrait)：
  .char portrait                  查看当前头像
  .char portrait <文件路径>       设置头像
  .char portrait open             用系统默认程序打开头像
  .char portrait clear            清除头像


✨ 法术位 (.ss)
───────────────────────────────────────────────────────────────
  .ss                    查看当前法术位
  .ss init               按角色等级自动初始化法术位
  .ss init 4 3 2 1       手动设定 (1环4个, 2环3个...)
  .ss use <环数>         消耗一个法术位
  .ss restore [环数]     恢复指定环位的法术位


🛌 休整
───────────────────────────────────────────────────────────────
  .longrest              长休：恢复全部HP/法术位、重置死亡豁免、恢复生命骰
  .shortrest [骰数]      短休：消耗生命骰恢复HP (每骰+体质调整值)，不填数量则用全部


🗺️ 随机事件表 (每次事件消耗1小时游戏时间)
───────────────────────────────────────────────────────────────

主表 (顶层掷表，触发后自动链式掷子表)：
  .zy100     随机遭遇 (d100)  环境变化/人类/野兽/迷失/友善生物/恶霜现象/特殊事件/特殊生物
  .ts100     随机探索 (d100)  继续深入/遭遇/采集资源/调查附近/修整/返回
  .dc100     随机调查 (d100)  特殊发现/踪迹/异常/材料/一无所获
  .qsj100    全随机事件 (d100)  混合所有子表的综合大表

维度子表 (环境/遭遇类，可独立使用或被主表链式触发)：
  .hj6       随机环境 (d6)     雪坑/暴风雪/极光/霜雾/冻雨/暖风
  .rl100     随机人类 (d100)   商队/公会/士兵/猎人
  .ys10      随机野兽 (d10)    冰原狼/野猪/白熊/巨熊/巨鹰/寒脊蛇
  .sj6       随机特殊事件 (d6) 雪崩/冰层破裂/冰层震动/陷阱/特殊标记/寒鸦报信
  .zl12      随机非敌对生物 (d12)  雪蹄兔/野鹿/雪鸮/寒鸦/雪狐/霜鼠/麝牛/银蛛/霜羽雉/绒蜂巢
  .sw100     随机特殊生物 (d100)  霜巨魔/恶尸/冬之氏族精灵/霜灵/瘦鹿/水星守卫

资源表 (产出自动添加到角色背包)：
  .cl50      随机材料 (d50)    药草/浆果/松枝/松脂/兽骨/矿粒/钱袋/特殊材料
  .fx100     随机特殊发现 (d100)  遗迹/灵泉/猎人小屋/温泉/岩洞/矿坑
  .yj8       随机遗迹 (d8)     远古战场/巨兽骨骸/墓穴/符文法阵/神殿/石碑/倒塌建筑/祭坛
  .cl100     随机特殊材料 (d100)  荧光苔/松茸/铁松松脂/绒蜂蜜/银蛛蛛网/霜晶核/寒铁髓
  .kw100     随机矿物 (d100)   盐/煤/铜/铁/寒铁矿/银/金/冰水晶/霜晶核/化石/宝石

其他：
  .wp [编号] 物品表查询 (1-29)，不填编号则列出全部

链式事件系统特性：
  · 最多支持5层深度链式掷表
  · 自动技能/豁免检定 (使用当前活跃角色数据)
  · 资源类事件自动拾取到角色背包/钱币
  · 生物数量自动投掷 (如"冰原狼(1d4只)"自动掷出具体数量)


📚 资料库查询 (五版不全书 CHM + SRD + 项目文件)
───────────────────────────────────────────────────────────────
  .spell <名称> [-d]      法术查询 (936条)，-d 显示完整描述
  .monster <名称> [-d]    怪物查询 (557条)，-d 显示详细数据
  .search <关键词>        综合搜索 (规则+法术+怪物+项目文件)
  .condition <名称>       DND5E 状态效果查询
  .file [关键词] [类别]   搜索项目资料文件，.file 查看文件库统计
                          类别：规则书/设定/地图/角色卡/模组/怪物面板/历史/笔记/职业/种族/魔法/神系

  .log                    导出本次会话跑团记录为 TXT (含目录/收获总结/详细记录)

🗺️ 战术地图 (/map) ★核心功能
───────────────────────────────────────────────────────────────

  双行可折叠工具栏：
    第一行（始终可见）：
      选择(单体/框选) | 导入地图 | 存档 | 图层 | 适应 | 重置 | 锁定 | 放大 | 缩小 | [▼展开]
    第二行（可折叠）：
      画笔 | 橡皮 | 填充 | 战争迷雾 | 文字 | 画笔颜色 | 画笔大小 | 角色 | 清除涂画 | 全部清除 | 法术/事件/战斗链接

  地图图层系统：
    · 支持导入多张地图图片作为图层 (png/jpg/gif/webp/bmp)
    · 图层独立控制：显示/隐藏、缩放 (🔍+/-)、上下移动、重命名、删除
    · 活动图层可独立拖拽平移（图层移动模式）
    · 图层数据以 base64 编码存入 IndexedDB，突破 localStorage 5MB 限制
    · 战争迷雾图层始终置顶

  绘图工具：
    · ✏️ 画笔：自由绘制，可调颜色和大小 (1-1000px)
    · 🧹 橡皮：擦除涂画内容
    · 🪣 填充：区域洪水填充（限定 800×800 采样区防止卡顿）
    · 🔤 文字：点击放置文字框，双击编辑，右下角拖拽调大小
    · 所有涂画保存到存档

  战争迷雾：
    · 点击添加多边形顶点，Shift+点击闭合当前区域
    · 支持多个迷雾区域
    · 可见/隐藏切换、删除全部迷雾

  角色标记：
    · 从侧边栏拖拽角色到地图上（头像圆形标记）
    · 拖拽移动、右下角调大小、旋转（R键/Alt+滚轮/顶部手柄）
    · 选中后左侧弹出角色信息面板（属性/HP/AC/装备）
    · 双击删除标记
    · 支持框选多选、群组拖拽

  快捷键：
    V 选择  B 画笔  E 橡皮  F 填充  G 迷雾  T 文字
    R 旋转选中标记  0 适应画面  Delete 删除选中  Esc 取消选择

  多存档系统：
    · 💾 存档下拉菜单：保存当前为...、已保存场景列表
    · 每个存档有：🔄切换 💾覆盖保存 ✏️重命名 ✕删除
    · 存档名自定义，支持重名覆盖
    · 数据存入 IndexedDB（大容量，支持含地图图片的完整快照）
    · 点击 💾 按钮显式保存（不自动覆盖存档）
    · 自动保存崩溃恢复兜底 (dnd_map_state)
    · 首次使用时自动迁移旧 localStorage 数据到 IndexedDB
    · 页面返回时自动恢复到上次激活的存档

  画面控制：
    · 滚轮缩放 / 🔍+ 🔍- 按钮
    · 📐 适应：根据画布内容自动调整缩放和位置
    · 🏠 重置：重置视角到内容居中
    · 🔓/🔒 锁定地图禁止平移缩放
    · 右键拖拽平移

  底部骰子栏：
    · 快速掷骰表达式输入
    · 优势/劣势/正常切换
    · 快捷按钮：d20 / 优势 / 劣势 / d6 / d8 / 3d6 / 4d6k3 / 2d6+3 / 察觉 / 隐匿
    · 可折叠

💾 数据存储架构
═══════════════════════════════════════════════════════════════

  资料库（只读索引）：
    CHM 规则书 → 手动解包为 HTML → chm_indexer.py 预建 JSON 索引
    spells_full.json (503KB)     法术全文索引 (936条)
    monsters_full.json (190KB)   怪物全文索引 (557条)
    chm_search_index.json (5.8MB)  全文搜索索引
    chm_inverted_index.json (2.3MB) 倒排索引
    chm_extracted/               CHM 解包 HTML 详情页
    project_files.json (106KB)   项目文件索引
    运行时仅读取 JSON 索引，不访问原始 CHM

  角色数据库（读写）：
    data/characters.db (SQLite)   11张表：角色/属性/技能/豁免/法术位/
                                  死亡豁免/武器/护甲/钱币/法术/物品/背景

  地图存档（读写）：
    IndexedDB: dnd_map_db        完整地图快照（图层 dataURL、涂画、标记、迷雾）
    localStorage: dnd_map_slots  存档索引（轻量元数据）
    自动崩溃恢复：dnd_map_state (IndexedDB)

  其他静态数据：
    skills.json / conditions.json / srd_spells.json / srd_monsters.json

📱 PE版（手机适配版）— dnd_bot_pe.py
═══════════════════════════════════════════════════════════════

文件位置: D:\游戏\尘封之卷-九子的注视\骰娘pe版\dnd_bot_pe.py
运行方式: python dnd_bot_pe.py [--port 8080] [--lan]
框架: Flask Web 服务器（默认端口 5001）
适用平台: iOS (Pythonista/a-shell) / Android (Termux/Pydroid 3)

【PE版概述】
  一个完整的 Flask REST API + 移动端单页应用(SPA)
  将命令行骰娘的所有功能包装为 HTTP API，并提供触屏优化的 Web UI
  通过手机浏览器访问 http://<地址>:5001 即可使用

【PE版 API 接口（共 30+ 个端点）】

  命令处理:
    POST /api/cmd                    处理任意命令（调用 _bot.COMMAND_MAP）
    GET  /api/log                    下载跑团记录(TXT)
    POST /api/log/clear              清空会话记录
    GET  /api/log/view               查看会话记录(JSON)

  角色管理 (RESTful API):
    GET    /api/characters                  列出所有角色
    POST   /api/character/create            创建角色
    GET    /api/character/<id>              获取角色概要
    GET    /api/character/<id>/detail       获取完整角色数据(JSON+HTML)
    POST   /api/character/<id>/select       切换活跃角色
    POST   /api/character/<id>/delete       删除角色
    POST   /api/character/<id>/hp           调整HP
    POST   /api/character/<id>/rest         长休/短休
    POST   /api/character/<id>/ability      设置属性值
    POST   /api/character/<id>/skill        设置技能熟练/专精
    POST   /api/character/<id>/save-prof    设置豁免熟练
    POST   /api/character/<id>/weapon/add   添加武器
    POST   /api/character/<id>/weapon/<wid>/remove  删除武器
    POST   /api/character/<id>/coin/adjust  调整钱币
    POST   /api/character/<id>/item/add     添加物品
    POST   /api/character/<id>/item/<iid>/remove    删除/减少物品
    POST   /api/character/<id>/item/<iid>/update    设置物品数量
    POST   /api/character/<id>/item/stack            合并重复物品
    POST   /api/character/<id>/spell/add             添加已准备法术
    POST   /api/character/<id>/spell/clear           清空法术列表
    POST   /api/character/<id>/spell-slot            消耗法术位
    POST   /api/character/<id>/spell-slots/init      按等级初始化法术位
    POST   /api/character/<id>/spell-slot/restore    恢复法术位
    POST   /api/character/<id>/background            设置背景字段
    POST   /api/character/<id>/death-save            掷死亡豁免

  战斗系统:
    POST   /api/combat/add              添加战斗者（自动投d20先攻）
    POST   /api/combat/next             下一回合
    GET    /api/combat/status           查看战斗状态
    POST   /api/combat/clear            清空先攻
    POST   /api/combat/remove           移除战斗者
    POST   /api/combat/hp               调整战斗者HP

  随机事件:
    POST   /api/event/<cmd>             触发指定事件表（zy100/ts100/dc100/hj6等16种）

  资料查询:
    GET    /api/spell?q=                法术查询(SRD)
    GET    /api/monster?q=              怪物查询(SRD)
    GET    /api/conditions?q=           状态查询
    GET    /api/chm/spell?q=            法术查询(CHM数据库)
    GET    /api/chm/monster?q=          怪物查询(CHM数据库)
    GET    /api/chm/search?q=           综合搜索(CHM)
    GET    /api/chm/rule?q=             规则搜索
    GET    /api/chm/item?q=             物品/装备搜索
    GET    /api/chm/feat?q=             专长搜索

  地图与资源:
    GET    /api/maps                    列出地图文件
    GET    /maps/<filename>             提供地图图片
    GET    /api/resources?cat=          列出资源文件(可按类别筛选)

【目录结构关系】
  项目目录/
    ├── 骰娘/                    ← 命令行版（核心引擎 + Web界面）
    │   ├── dnd_bot.py           （CLI入口 + 命令处理器 + 事件表系统）
    │   ├── core/                （核心模块：骰子引擎/规则/角色/战斗/CHM搜索）
    │   ├── utils/               （工具：数据加载/Excel导入/格式化）

    │   └── data/                （SQLite 角色数据库 + JSON 索引文件）

        └── resources/           （资源文件目录）

【代码级联动】

  1. 模块导入复用:
     dnd_bot_pe.py 通过以下代码将骰娘/目录加入Python路径：
       DICE_DIR = SCRIPT_DIR.parent / '骰娘'
       sys.path.insert(0, str(DICE_DIR))
     然后直接 import dnd_bot as _bot，将整个命令行版作为模块导入

  2. 命令处理完全共享:
     dnd_bot_pe.py 的 process_command() 函数直接调用 _bot.COMMAND_MAP
     这意味着PE版的 /api/cmd 端点是命令行版命令处理器的HTTP包装
     PE版无需重复实现任何命令逻辑

  3. 核心模块共享:
     两个版本导入完全相同的核心模块：
     · core.dice_engine       — 骰子引擎（掷骰/检定/攻击/伤害/先攻/死亡豁免/属性生成）
     · core.dnd5e_rules       — D&D 5E规则计算（属性调整值/技能映射/熟练加值/豁免/法术位）
     · core.character         — 角色数据管理（SQLite CRUD，11张表）
     · core.combat            — 战斗先攻追踪器
     · core.chm_search        — CHM规则书全文搜索引擎
     · utils.data_loader      — SRD数据加载器
     · utils.formatter        — ANSI格式化输出
     · utils.excel_importer   — Excel人物卡导入器

  4. 数据库完全共享:
     dnd_bot_pe.py 设置环境变量指向骰娘/data/目录：
       os.environ.setdefault('DND_DB_DIR', str(DICE_DIR / 'data'))
     两个版本使用同一个 SQLite 数据库（characters.db）
     角色数据实时互通：命令行版创建的角色，PE版立即可见

  5. 事件表系统联动:
     dnd_bot_pe.py 的 EVENT_COMMANDS 字典直接引用 _bot 的事件命令函数：
     · _bot.cmd_zy100, _bot.cmd_ts100, _bot.cmd_dc100, _bot.cmd_qsj100
     · _bot.cmd_hj6, _bot.cmd_rl100, _bot.cmd_ys10, _bot.cmd_sj6
     · _bot.cmd_zl12, _bot.cmd_sw100
     · _bot.cmd_cl50, _bot.cmd_cl100, _bot.cmd_kw100
     · _bot.cmd_fx100, _bot.cmd_yj8, _bot.cmd_wp
     PE版的 /api/event/<cmd> 端点直接调用这些函数
     事件表数据（TABLE_ITEM_ACTIONS等）只在 dnd_bot.py 中定义一处

  6. 格式化输出复用:
     两个版本共用 formatter 模块的 ANSI 格式化函数
     PE版额外增加 _ansi_to_html() 将ANSI转HTML：
     · 粗体 → <b>
     · 红色(31m) → #ff6b6b
     · 绿色(32m) → #51cf66
     · 青色(36m) → #66d9e8
     · 黄色(33m) → #ffd43b

  7. CHM搜索联动:
     PE版直接导入 core.chm_search 的所有搜索函数
     同时提供 SRD 回退（命令行版的 .spell/.monster 也使用同样的回退逻辑）

  8. 帮助系统联动:
     PE版的命令帮助展示完全引用 _bot 的 cmd_help 函数
     事件表分组信息（EVENT_GROUPS）在PE版中单独维护以适配卡片UI

【运行模式互补】
  · 命令行版: 桌面端DM使用，支持交互模式和脚本化
  · PE版: 手机/平板浏览器使用，触屏优化的完整Web UI
  · 两者可同时运行：DM用命令行版，玩家用手机浏览器连接PE版
  · 共享数据库：角色数据在两个版本间实时同步
  · PE版支持 --lan 参数允许局域网访问，方便全桌玩家连接

【数据流对比】

  命令行版:
    用户输入文本 -> process_command() -> COMMAND_MAP路由 -> 命令处理器
    -> core模块计算 -> formatter格式化(ANSI) -> 终端输出 -> 记录到 _session_log

  PE版:
    用户触屏/输入 -> JavaScript fetch -> Flask API端点
    -> process_command()（调用 _bot.COMMAND_MAP）-> core模块计算
    -> formatter格式化(ANSI) -> _ansi_to_html()转HTML -> JSON响应
    -> JavaScript渲染到页面消息区
    事件表API: 直接调用 _bot.cmd_xxx() 事件函数

【两者差异】
  · 命令行版 --web 模式启动了 web/app.py（另一个Web界面，多页导航）
  · PE版是完全独立的 Flask 应用，SPA单页架构，专为手机触屏优化
  · PE版新增了地图服务器、资源库服务器、多用户IP区分等特性
  · PE版的事件面板使用卡片网格UI，比命令行的命令输入更直观
