🎲 3D掷骰主页（/ 或 /dice3d）★核心掷骰界面
═══════════════════════════════════════════════════════════════

  底部三Tab控制栏：
    🎲掷骰  |  🎯检定  |  🛡豁免

  ── 🎲 掷骰 Tab ──
    骰子类型：d4 / d6 / d8 / d10 / d12 / d20 / d100
    个数步进器：1-40
    加值步进器：-99 ~ +999
    模式切换：正常 | 优势 | 劣势
    爆炸骰：投出最大值追加一粒（如 3d6!）
    保留/丢弃：保留最高(kh) / 保留最低(kl) / 丢弃最高(dh) / 丢弃最低(dl)
    快捷预设：3d6 / 4d6k3 / 2d6+3 / 8d6 / 1d8+2 / 1d20+5 / d20优势 / d20劣势
    自定义表达式：支持任意格式（如 2d8+1d6+3 / adv d20+5）
    桌布切换：12种预设（木桌/蓝毡/石板/大理石/草地/雪地/冰面/星空）+ 自定义上传
    暗骰按钮：仅DM可见，启用后本地播放3D动画但不广播（结果仅自己可见）

  ── 🎯 检定 Tab ──
    角色选择器（联动角色数据，自动读取属性/熟练加值）
    检定输入框 + 优劣势切换
    18个技能快捷按钮（按属性分组）：
      力量：运动
      敏捷：特技 / 巧手 / 隐匿
      智力：奥秘 / 历史 / 调查 / 自然 / 宗教
      感知：驯兽 / 洞悉 / 医药 / 察觉 / 生存
      魅力：欺诈 / 威吓 / 表演 / 游说
    属性生成：4d6k3 × 6 组

  ── 🛡 豁免 Tab ──
    角色选择器（独立，不冲突其他Tab）
    6属性豁免：力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力
    优劣势切换
    点击属性直接掷d20豁免 + 3D动画（自动读取角色豁免熟练加值）

  ── 3D物理骰子引擎 ──
    dice-engine-v3（Three.js + cannon-es 物理引擎）
    真3D物理碰撞、滚动动画
    确定性骰子格式：API结果 → "2d20@17,5" → box.roll() → 物理动画
    d100特殊处理：API返回单个值 → 拆分为两个d10骰子动画（如83→"2d10@8,3"）

  ── 联机同步 ──
    WebSocket（/ws）实时广播掷骰事件
    格式：dice_roll_det（原版协议，未修改）
    发送方：API获取结果 → 立即广播 detNotation + 本地动画
    接收方：收到 detNotation → 同步播放3D动画
    同步延迟：约网络延迟+动画时间（两端几乎同时）

  ── 左侧聊天面板 ──
    滑出式面板（280px），展开时主界面右移
    消息轮询（3秒）+ 发送
    在线人数 + 在线用户列表（带ID颜色，DM金色👑标识）
    心跳8秒保活（防止10秒超时清理）
    复用加入覆盖层的身份信息，无需重复登录

  ── 加入覆盖层 ──
    ID输入 + 20色选择器 + DM/PL身份选择
    DM自动检测（金色ID标识）
    已加入用户跳过（sessionStorage记忆）
    暗骰按钮仅DM可见

  ── 检定/豁免结果显示 ──
    3D d20骰子动画
    浮层显示完整信息：名称 / 检定类型 / 结果 / 优劣势 / d20值 / 属性加值 / 熟练加值 / 暴击

🎲 掷骰
───────────────────────────────────────────────────────────────
  .r <表达式>              通用掷骰 (3d6 / d20+5 / 4d6k3 / 3d6!)

  .ds                               死亡豁免

🔐 身份系统（DM / PL）
═══════════════════════════════════════════════════════════════

  【加入房间】
    打开任何页面 → 加入覆盖层 → 输入ID / 选择颜色 / 选择身份
    ┌─────────────────────────────────────────────────────────┐
    │ 👑 DM（主持人）  → 地图编辑 / 迷雾 / 暗骰 / 战斗管理  │
    │ 🎭 PL（玩家）    → 只读战斗 / 不可迷雾 / 无暗骰按钮   │
    └─────────────────────────────────────────────────────────┘

  【身份锁定】
    加入时选择的身份在本次会话永久锁定。
    切换页面 / 刷新浏览器 不会改变身份。
    重新打开浏览器并加入房间才能更换身份。

  【ID 唯一性】
    同一 ID 不可被多人同时使用。
    刷新页面时同 IP 自动放行（不会锁定自己）。
    10 秒无心跳自动清理离线用户。

  【在线检测】
    心跳间隔：8 秒（安全余量，低于10秒清理阈值）
    离线超时：10 秒无心跳 → 自动退出消息 + 清理
    加入/心跳时自动清理过期用户

🗺️ 战术地图 (/map) ★核心协作功能
═══════════════════════════════════════════════════════════════

  【实时同步（自动，无需手动操作）】
    · 所有用户进入地图页面后自动连接共享画布
    · DM/PL 的涂画、标记、文字操作实时广播给所有在线用户
    · 图层变更自动推送
    · WebSocket（/ws）+ HTTP 轮询双通道

  【手动同步（备用）】
    · DM 📤 推送按钮：全量写入服务端（含地图图层 dataURL）
    · PL 🔄 同步按钮：全量拉取服务端共享画布

  【工具栏（双行可折叠）】
    第一行：选择 | 画笔 | 橡皮 | 填充 | 迷雾 | 文字 | 颜色 | 大小
           导入 | 地图 | 资源库 | 存档 | 图层 | 适应 | 重置 | 锁定 | 缩放
    第二行：导航链接（3D掷骰/角色卡/战斗/法术/事件/参考/聊天室）

  【图层系统】
    · 导入多张地图图片作为图层
    · 独立控制：显示/隐藏、缩放、移动、重命名、删除
    · 图层 dataURL 存储在服务端，PL 通过单独 URL 加载（减小 JSON 体积）

  【绘图工具】
    · ✏️ 画笔：自由绘制，可调颜色 (色轮) 和大小 (1-1000px)
    · 🧹 橡皮：擦除涂画
    · 🪣 填充：区域洪水填充
    · 🔤 文字：点击放置文字框，双击编辑
    · 快捷键：V选择 B画笔 E橡皮 F填充 G迷雾 T文字

  【战争迷雾】
    DM 视角：半透明深灰，可看到下方内容
    PL 视角：完全不透明实心灰色（无法看到下方任何内容）
    PL 不可使用迷雾绘制/删除功能（按钮隐藏 + 代码级阻止）

  【角色标记】
    · 从侧边栏拖拽角色到地图（圆形头像标记）
    · 拖拽移动、调整大小、旋转
    · 选中后左侧弹出角色信息面板
    · 双击删除标记

  【PL 功能限制】
    · 不可使用：战争迷雾 / 清除涂画 / 全部清除
    · 迷雾区域完全不透明
    · 战斗面板只读
    · 按钮被隐藏 + 代码级阻止（双重保障）

  【存档系统】
    · 多存档槽位（命名、切换、覆盖、重命名、删除）
    · IndexedDB 存储（支持大体积地图图片）
    · 自动保存（每 3 秒）
    · 页面离开时立即保存
    · 刷新页面自动恢复

  【底部骰子栏】
    表达式输入 | 优势/劣势/正常 | d20/优势/劣势/d6/d8/3d6/4d6k3/察觉/隐匿
    ✨3D按钮：嵌入3D掷骰iframe（物理骰子动画）

🔄 共享画布 & 3D骰子同步 技术架构
═══════════════════════════════════════════════════════════════

  【3D骰子同步】
    · 协议：dice_roll_det（原版确定性骰子格式，未修改）
    · 发送方：API获取结果 → 构建 detNotation("2d20@17,5") → 立即WS广播 → 本地播放3D动画
    · 接收方：WS收到 detNotation → box.roll() 同步播放 → 显示结果浮层
    · 广播先于本地动画，两端延迟最小化
    · 暗骰模式：跳过WS广播和聊天消息，仅本地播放动画+显示结果

  【共享画布同步】
    · 主通道：WebSocket (/ws, 端口 5000) — 实时增量广播
    · 备用通道：HTTP 轮询 (/api/shared-canvas) — 300ms 增量拉取
    · 手动通道：📤 推送 / 🔄 同步按钮 — 全量写入/读取

  【服务端存储】
    · 内存：shared_state 模块（笔画/图层/标记/文字/迷雾）
    · 磁盘：web/shared_canvas.json（3 秒防抖自动保存）
    · 启动时自动从磁盘恢复

  【图层图片优化】
    · 同步响应的 JSON 不包含 dataURL（仅元数据）
    · 图层图片通过 /api/shared-canvas/layer/<id> 端点单独加载
    · 避免大体积 JSON 导致 FRP 传输超时

  【增量同步】
    · 笔画：每笔单独追加（不发送全部历史）
    · 标记/文字：按 id 增量合并
    · 图层：元数据增量，图片按需加载
    · 迷雾：全量替换
