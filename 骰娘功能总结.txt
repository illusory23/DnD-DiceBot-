3. 北境雪原 & 北境探索（/north-expedition）★新核心玩法
═══════════════════════════════════════════════════════════════════

  ── 概述 ──
    北境探索是一个独立的 DND 生存冒险系统，玩家在冰霜废土中
    进行探索、生存管理、战斗和资源收集的沉浸式体验。
    与事件表系统关联（共用 qsj100/ts100/dc100 主表及子表数据），
    但拥有独立的前端引擎和生存机制。

  ── 页面布局（双栏）──
    左侧（主区域）：事件回响日志（从下到上排列，最近16条）
    右侧（侧边栏）：冒险者面板 → 生存状态 → 营地书页 → 角色卡
    底部：事件按钮栏 + 背包按钮

  ── 角色创建与选择 ──
    · 支持选择已有角色卡（联动角色数据库）
    · 支持快速创建预设角色（默认属性模板）
    · 冒险者面板显示：用户 ID + 等级徽章 + 角色详情
    · 角色数据独立存储（localStorage），不修改原始角色卡

  ═══════════════════════════════════════════════════════════════
  🧭 事件系统
  ═══════════════════════════════════════════════════════════════

  ── 事件按钮（4个功能按钮）──
    🔍 探索雪原：调查附近(dc100) / 深入雪原(ts100)
    🎯 搜索资源：cl50 / cl100 / kw100 / fx100 / yj8
    🌿 环境观察：hj6 / sj6 / rl100 / ys10
    🐺 生物遭遇：zl12 / sw100

  ── 调查附近（dc100）──
    · 最多连续点击 5 次
    · 第 6 次提示"附近没有什么能调查的了"
    · 返回营地/继续探索触发方向判断检定

  ── 方向判断 ──
    · DC 固定 15（不受迷失惩罚叠加影响）
    · 视为一次完整事件（触发全部生存检定）
    · 成功：定向移动；失败：迷失层数 +1 📍

  ── 链式事件 ──
    · 主表结果自动链式掷子表（最多 5 层嵌套）
    · 后台完整执行所有层级，前端仅显示最终结果
    · 事件描述自动清理链式机制文字，仅保留场景描写和 DC 条件
    · 骰子表达式在运行时自动掷出并替换为实际数字

  ── 生物遭遇 ──
    · 显示"遭遇 X 只 生物名"前缀
    · 敌对生物（⚔️）：出现战斗/逃离按钮
    · 中立生物（🌿）：仅观察描述

  ── 遗迹/矿坑探索 ──
    · 遗迹条目仅展示检定条件，隐藏奖励结果
    · 搜索资源期间事件锁定
    · 材料确认后自动添加到背包

  ═══════════════════════════════════════════════════════════════
  ❄️ 生存系统
  ═══════════════════════════════════════════════════════════════

  ── 严寒系统 ──
    · 三级严寒：轻度 → 中度 → 重度（3 格显示）
    · 严寒检定：d20 + 体质豁免熟练加值 vs DC（庇护所内 10，野外 12）
    · 失败：严寒等级 +1
    · 庇护所长休：全部解除
    · 庇护所短休：解除 1 级
    · 生火：解除 1 级（可重复添柴续火）

  ── 口粮系统 ──
    · 口粮独立统计，优先消耗
    · 庇护所内暂停计数和消耗
    · 断粮扣血：每 3 次事件触发 1d4 生命流失
    · 饥饿标记显示当前状态

  ── 食物系统 ──
    · 食物（浆果/野菜、兽肉等）存入背包，不直接增加口粮
    · 口粮归零时自动消耗背包食物替代
    · 背包食物统计独立显示

  ── 燃料系统 ──
    · 燃料类型：松枝 / 松脂 / 荧光苔 / 铁松松脂（按消耗优先级排序）
    · 铁松松脂按 2 份燃料计算
    · 庇护所内不消耗燃料
    · 长休需 4 份燃料，短休需 1 份
    · 燃料不足时提示具体缺口
    · 燃料统计显示总份数

  ── 生火系统 ──
    · 可重复点击（添柴续火）
    · 每次消耗 1 份燃料延长 2 次事件的照明效果
    · 生火同时解除 1 级严寒

  ── 昏迷系统 ──
    · HP ≤ 0 触发昏迷
    · 消息叠加不覆盖（可触发多次）
    · 昏迷期间所有操作锁定
    · 次日自动恢复满状态回到营地

  ═══════════════════════════════════════════════════════════════
  ⚔️ 战斗与逃离
  ═══════════════════════════════════════════════════════════════

  ── 战斗 ──
    · 敌对生物遭遇显示战斗/逃离选择按钮
    · 战斗伤害：1d6+2
    · 先显示伤害再判定昏迷
    · 遭遇期间锁定事件，战斗结束后解锁

  ── 逃离 ──
    · 隐匿检定 DC 15（有熟练加值）
    · 显示完整骰点（d20 + 属性加值 + 熟练加值）
    · 失败同样先显示伤害再判定昏迷
    · 封锁事件至战斗/逃离完成

  ═══════════════════════════════════════════════════════════════
  ⛺ 营地系统
  ═══════════════════════════════════════════════════════════════

  ── 原地休整 ──
    · 事件回响内显示长休/短休选择按钮
    · 需要燃料方可休整（长休 4 份 / 短休 1 份）
    · 无燃料提示"无法进行原地休整"
    · 自动消耗燃料、搭建临时营地（庇护所）

  ── 扎营 ──
    · 主动建立庇护所
    · 猎人小屋/天然温泉/岩洞不再设置永久庇护所
    · 庇护所效果：口粮暂停消耗、燃料暂停消耗、严寒 DC 降至 10

  ── 长休 ──
    · 恢复全部 HP + 解除全部严寒
    · 重置迷失层数
    · 需要 4 份燃料

  ── 短休 ──
    · 可消耗生命骰恢复 HP
    · 解除 1 级严寒
    · 需要 1 份燃料

4. 3D掷骰主页（/dice3d-e）★核心掷骰界面
═══════════════════════════════════════════════════════════════════

  注：/dice3d 现已自动重定向到 /dice3d-e（保留查询参数）

  ── 底部三 Tab 控制栏 ──
    🎲 掷骰  |  🎯 检定  |  🛡 豁免

  ── 🎲 掷骰 Tab ──
    骰子类型：d4 / d6 / d8 / d10 / d12 / d20 / d100
    个数步进器：1-40
    加值步进器：-99 ~ +999
    模式切换：正常 | 优势 | 劣势
    爆炸骰：投出最大值追加一粒（语法：3d6!）
    保留/丢弃：kh（保留最高）/ kl（保留最低）/ dh（丢弃最高）/ dl（丢弃最低）
    快捷预设：3d6 / 4d6k3 / 2d6+3 / 8d6 / 1d8+2 / 1d20+5 / d20优势 / d20劣势
    自定义表达式：支持任意格式（如 2d8+1d6+3 / adv d20+5）
    桌布切换：12种预设（木桌/蓝毡/石板/大理石/草地/雪地/冰面/星空）+ 自定义上传
    暗骰按钮：仅 DM 可见，本地播放3D动画但不广播（结果仅自己可见）

  ── 🎯 检定 Tab ──
    角色选择器（联动角色数据，自动读取属性/熟练加值）
    检定输入框 + 优劣势切换
    18个技能快捷按钮（按属性分组）：
      力量 ─ 运动
      敏捷 ─ 特技 / 巧手 / 隐匿
      智力 ─ 奥秘 / 历史 / 调查 / 自然 / 宗教
      感知 ─ 驯兽 / 洞悉 / 医药 / 察觉 / 生存
      魅力 ─ 欺诈 / 威吓 / 表演 / 游说
    属性生成：4d6k3 × 6 组

  ── 🛡 豁免 Tab ──
    角色选择器（独立，不冲突其他 Tab）
    6属性豁免：力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力
    优劣势切换
    点击属性直接掷 d20 豁免 + 3D 动画（自动读取角色豁免熟练加值）

  ── 3D 物理骰子引擎 ──
    引擎：dice-engine-v3（Three.js + cannon-es 物理引擎）
    特性：真3D 物理碰撞、滚动动画、真实重力模拟
    确定性骰子格式：API 结果 → "2d20@17,5" → box.roll() → 物理动画
    d100 特殊处理：API 返回单个值 → 拆分为两个 d10 骰子动画（如 83 → "2d10@8,3"）

  ── 联机同步 ──
    协议：WebSocket（/ws）实时广播掷骰事件
    格式：dice_roll_det（原版确定性骰子协议，未修改）
    发送方：API 获取结果 → 立即广播 detNotation + 本地动画
    接收方：收到 detNotation → 同步播放 3D 动画
    同步延迟：约网络延迟 + 动画时间（两端几乎同时）

  ── 左侧聊天面板 ──
    滑出式面板（280px），展开时主界面右移
    消息轮询（3秒）+ 消息发送
    在线人数 + 在线用户列表（带 ID 颜色，DM 金色👑标识）
    心跳 8 秒保活（防止 10 秒超时清理）
    复用加入覆盖层的身份信息，无需重复登录

  ── 加入覆盖层 ──
    ID 输入 + 20色选择器 + DM/PL 身份选择
    DM 自动检测（金色 ID 标识）
    已加入用户跳过（sessionStorage 记忆）
    暗骰按钮仅 DM 可见

  ── 检定/豁免结果显示 ──
    3D d20 骰子动画
    浮层显示完整信息：名称 / 检定类型 / 结果 / 优劣势 / d20值 / 属性加值 / 熟练加值 / 暴击

5. 战术地图（/map）★核心协作功能
═══════════════════════════════════════════════════════════════════

  ── 实时同步（自动，无需手动操作）──
    · 所有用户进入地图页面后自动连接共享画布
    · DM/PL 的涂画、标记、文字操作实时广播给所有在线用户
    · 图层变更自动推送
    · WebSocket（/ws）+ HTTP 轮询双通道

  ── 手动同步（备用）──
    · DM 📤 推送按钮：全量写入服务端（含地图图层 dataURL）
    · PL 🔄 同步按钮：全量拉取服务端共享画布

  ── 工具栏（双行可折叠）──
    第一行：选择 | 画笔 | 橡皮 | 填充 | 迷雾 | 文字 | 颜色 | 大小
           导入 | 地图 | 资源库 | 存档 | 图层 | 适应 | 重置 | 锁定 | 缩放
    第二行：导航链接（3D掷骰 / 角色卡 / 战斗 / 法术 / 事件 / 参考 / 聊天室）
    快捷键：V选择 B画笔 E橡皮 F填充 G迷雾 T文字
    画笔大小范围：1-1000px
    颜色选择：色轮取色器

  ── 图层系统 ──
    · 导入多张地图图片作为图层
    · 独立控制：显示/隐藏、缩放、移动、重命名、删除
    · 图层 dataURL 存储在服务端，PL 通过单独 URL 加载（减小 JSON 体积）

14. 身份系统（DM / PL / 房间）
═══════════════════════════════════════════════════════════════════

  ── 加入房间 ──
    打开任何页面 → 加入覆盖层 → 输入 ID / 选择颜色（20色）/ 选择身份
    ┌──────────────────────────────────────────────────────────┐
    │ 👑 DM（主持人）  → 地图编辑 / 迷雾 / 暗骰 / 战斗管理   │
    │ 🎭 PL（玩家）    → 只读战斗 / 不可迷雾 / 无暗骰按钮    │
    └──────────────────────────────────────────────────────────┘

  ── 身份锁定 ──
    加入时选择的身份在本次会话中永久锁定。
    切换页面 / 刷新浏览器不会改变身份。
    需要重新打开浏览器并加入房间才能更换身份。

  ── ID 唯一性 ──
    同一 ID 不可被多人同时使用。
    刷新页面时同 IP 自动放行（不会锁定自己）。
    10 秒无心跳自动清理离线用户。

  ── 在线检测 ──
    心跳间隔：8 秒（安全余量，低于 10 秒清理阈值）
    离线超时：10 秒无心跳 → 自动退出消息 + 清理
    加入/心跳时自动清理过期用户

  ── DM 自动检测 ──
    首个加入房间的用户自动成为 DM（金色👑标识）
    DM 离开后，剩余用户中最早加入的自动晋升为 DM
    检测逻辑在加入/心跳/离开三个时机触发

  ── FRP 兼容 ──
    frp 环境下所有用户 IP 显示为 127.0.0.1
    身份判定以用户加入时选择的 DM/PL 为准（不依赖 IP）
    多人共享 IP 时自动禁用 IP 检测

15. 共享画布 & 3D骰子同步 技术架构
═══════════════════════════════════════════════════════════════════

  ── 3D 骰子同步 ──
    协议：dice_roll_det（原版确定性骰子格式，未修改）
    发送方：API 获取结果 → 构建 detNotation("2d20@17,5") → 立即 WS 广播 → 本地播放 3D 动画
    接收方：WS 收到 detNotation → box.roll() 同步播放 → 显示结果浮层
    广播先于本地动画，两端延迟最小化
    暗骰模式：跳过 WS 广播和聊天消息，仅本地播放动画 + 显示结果

  ── 共享画布同步 ──
    主通道：WebSocket（/ws, 端口 5000）— 实时增量广播
    备用通道：HTTP 轮询（/api/shared-canvas）— 300ms 增量拉取
    手动通道：📤 推送 / 🔄 同步按钮 — 全量写入/读取

  ── 服务端存储 ──
    内存：shared_state 模块（笔画 / 图层 / 标记 / 文字 / 迷雾）
    磁盘：web/shared_canvas.json（3 秒防抖自动保存）
    启动时自动从磁盘恢复

  ── 图层图片优化 ──
    同步响应的 JSON 不包含 dataURL（仅元数据）
    图层图片通过 /api/shared-canvas/layer/<id> 端点单独加载
    避免大体积 JSON 导致 FRP 传输超时

  ── 增量同步策略 ──
    笔画：每笔单独追加（不发送全部历史）
    标记/文字：按 id 增量合并
    图层：元数据增量，图片按需加载
    迷雾：全量替换

  ── 骰子统计 ──
    Web 端每次 d20 掷骰自动记录到服务端 JSON（dice_stats.json）
    统计维度：总次数 / 暴击(20)次数 / 大失败(1)次数
    线程安全（threading.Lock）

    WS 路径：/ws（frp 自动转发 WebSocket 升级请求）

  ── 推荐工具 ──
    · ZeroTier（虚拟局域网，推荐 — 低延迟、无需公网 IP）
    · 樱花 FRP（内网穿透，仅需一个端口，已测试兼容）
    · ngrok（临时测试用）
