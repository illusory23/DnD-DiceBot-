1.1 设计理念
─────────────────────────────────────────────────────────────────────────────────

  营地中新增「🏪 交易站」功能，允许玩家用金币购买物资。
  商店物品基于事件表中的可获取材料反向推导——雪原上能捡到的，商人那里也能买到。
  每次进入营地时商店物品随机刷新（部分固定 + 部分随机）。

1.5 出售功能
─────────────────────────────────────────────────────────────────────────────────

  玩家可将背包中的物品出售给商店获得金币。

  出售规则：
  · 出售价 = 基础价 × 50%（半价回收）
  · WP物品表中有标价的按标价计算
  · 无标价的通用材料（兽骨/矿粒等）统一 1-3 GP
  · 支持批量出售（勾选多个物品一次性卖出）

  出售价目表示例：
  ┌──────────┬──────────┐
  │ 物品      │ 回收价    │
  ├──────────┼──────────┤
  │ 金矿      │ 7 GP     │
  │ 银矿      │ 1 GP     │
  │ 宝石      │ 5-25 GP  │
  │ 霜晶核    │ 3-5 GP   │
  │ 化石      │ 1-30 GP  │
  │ 普通兽骨  │ 1 GP     │
  │ 矿粒      │ 1 GP     │
  │ 药草      │ 2 GP     │
  └──────────┴──────────┘


1.6 技术实现要点
─────────────────────────────────────────────────────────────────────────────────

  · shopData 对象存储当前商店状态
  · 每次打开营地页面时调用 refreshShop() 随机刷新
  · 购买扣金币、加物品到背包
  · 出售加金币、从背包移除物品
  · 操作记录显示在事件回响

2.1 设计理念
─────────────────────────────────────────────────────────────────────────────────

  事件表中多处提到合成关系：
  · 药草 + 魔法泉水 → 2d4+2生命
  · 寒铁矿(1d6=6) → 寒铁髓
  · 兽肉烹饪 → 2d2份口粮
  · 松枝 → 制作火把

  将这些隐含的合成关系显式化，让玩家在营地中主动使用材料制作物品。

3.1 设计理念
─────────────────────────────────────────────────────────────────────────────────

  当前背包物品仅为静态列表。需要让物品可以「使用」产生实际效果。
  WP物品表中有多件物品标注了使用效果但从未实现：
  · 药草：独立使用→1d2生命或止血
  · 魔法泉水：单独饮用→下次智力优势
  · 松茸：食用→下次力量/体质优势
  · 绒蜂蜜：处理后食用→1d4生命+寒冷抗性；直接食用→1d3(2-3腹泻)
  · 松枝→制作火把
  · 铁松松脂→附赠动作涂抹武器，1d6火焰伤害
  · 白花藤→磨粉撒伤口，1d4生命

  当前背包物品右侧加「使用」按钮：

  · 使用后即时生效并显示系统提示
  · 可多次使用的物品（如药草×3）每次减1
  · 某些物品有多种用法（如药草：直接吃/合成），弹出选择


3.4 状态效果追踪
─────────────────────────────────────────────────────────────────────────────────

  需要新增一个临时状态系统来追踪物品效果：

  {
    tempEffects: {
      nextIntCheckAdvantage: false,   // 下次智力检定优势
      nextStrConCheckAdvantage: false,// 下次力量/体质优势
      fireWeaponBonus: 0,            // 武器火焰附魔剩余次数
      coldResistanceUses: 0,         // 寒冷抗性剩余次数
    }
  }

  下次对应检定时自动消耗效果并提示。


3.5 技术实现要点
─────────────────────────────────────────────────────────────────────────────────

  · itemActions 映射表定义每个物品的使用效果
  · 角色卡背包区为每个物品渲染对应的操作按钮
  · 使用后扣减物品数量，执行效果函数
  · 临时效果在下一次对应检定时自动触发
  · 营地页和探索页都支持物品使用

  · fullLog → localStorage['north_fulllog']（仅最近100条）
  · 商店状态 → localStorage['north_shop']

  保存时机：
  · 每次事件完成后
  · 每次营地操作后
  · 页面关闭前（beforeunload）


6.2 加载与重置
─────────────────────────────────────────────────────────────────────────────────

  · 页面加载时自动恢复所有数据
  · 营地设置中增加「🗑 重置存档」按钮（二次确认）
  · 版本号检测 → 数据结构变更时自动迁移或提示

8.1 探索地图
─────────────────────────────────────────────────────────────────────────────────

  一个简化的节点式地图，展示探索过的地点。

  节点类型（基于fx100事件结果）：
  · 🏠 猎人小屋（已发现/已访问）
  · ♨️ 天然温泉
  · 🏔️ 岩洞
  · ⛏️ 矿坑
  · 🏛 遗迹（yj8子结果细分）
  · 🌲 当前位置标记

  探索深度：从入口开始计算经过的事件数。

  地图操作：
  · 点击已知地点→显示详情
  · 标记当前位置
  · 返回已访问地点（消耗事件数）


8.2 技术实现要点
─────────────────────────────────────────────────────────────────────────────────

  · 用 exploration.discovered 数组记录已发现地点
  · 每次事件产生新发现时推入数组
  · 地图用SVG或Canvas绘制简单的雪原节点图
  · 地图状态加入 localStorage 持久化
