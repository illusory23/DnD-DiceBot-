## 二、等级与积分面板（已实现）

### 2.1 界面元素

```
┌─────────────────────────────────────────────┐
│  ⭐ 金羽（84px 圆形徽章，等级专属颜色）         │
│  金羽 冒险者                                  │
│  🗺️ 累计事件 350 次 | ⭐ 冒险者积分 500 分     │
│  ── 晋升进度条 ──                             │
│  → 赤羽          还需 170 次事件              │
│  ████████░░░░░░░（76% 填充）                 │
├─────────────────────────────────────────────┤
│  🏔️ 晋升之路（7 级阶梯横向卡片）               │
│  [青羽✓] [黑羽✓] [蓝羽✓] [银羽✓] [金羽⭐] [赤羽] [白羽] │
│   0     50     120    220    350    520    750 │
├─────────────────────────────────────────────┤
│  📜 冒险者积分说明                            │
│  · 每完成 1 次事件 +1 积分                    │
│  · 晋升奖励：黑羽+20 … 白羽+120               │
│  · 积分商店兑换（筹备中）                      │
└─────────────────────────────────────────────┘
```

### 2.2 阶梯状态语义

- **已完成**（`done`）：等级所需事件数已达成，绿框 + ✓ 标记
- **当前**（`current`）：玩家当前头衔，金色高亮 + ⭐ 标签 + 上浮
- **未达成**（`locked`）：灰色半透明

### 2.3 满级状态

白羽（最高级）时：晋升进度条自动隐藏，阶梯全部点亮（6 done + 1 current），
积分照常累积（积分商店后续版本开放消耗）。

## 三、晋升逻辑

### 3.1 等级表（数据：`web/static/north-data.js` → `RANK_LEVELS`）

| 头衔 | 所需累计事件 | 徽章颜色 | 晋升积分奖励 |
|---|---|---|---|
| 青羽（初始） | 0 | #9db4c8 | — |
| 黑羽 | 50 | #8a8aa0 | +10 |
| 蓝羽 | 120 | #5a8ac8 | +30 |
| 银羽 | 220 | #c0c0d8 | +60 |
| 金羽 | 350 | #ffd700 | +120 |
| 赤羽 | 520 | #e0555a | +200 |
| 白羽 | 750 | #ffffff | +400 |

> 设计稿中各等级特殊效果（严寒豁免/商店解锁/配方解锁/出售加成等）
> 经确认暂不实现，后续版本在 `RANK_LEVELS` 中扩展字段即可。

### 3.2 触发时机与计算（`web/static/north-main.js`）

- **基准**：`statsData.total`（累计事件数，即营地统计"总事件数"口径）
- **当前等级**：`getRankIndex(total)` —— 从高到低取第一个 `total >= need` 的等级
- **下一等级**：`getNextRank()` —— 未满级返回下一级，满级返回 `null`
- **晋升检查**：`checkRankUp(oldTotal, newTotal)` 在 `recordStat()` 中调用，
  检测到跨越等级门槛时：
  1. 追加晋升奖励积分（见下）
  2. 输出晋升播报：`✨✨ 冒险者等级晋升：金羽！累计事件 350 次，获得 80 冒险者积分`
  3. 刷新等级 UI

### 3.3 头衔显示范围

- **探索右栏冒险者面板** / **营地角色卡**：仅显示头衔徽章（等级颜色），
  悬停提示（`title`）显示累计事件与距下一级还需事件数
- **公会界面**：完整晋升进程可视化（进度条 + 阶梯）

## 四、冒险者积分获取逻辑

### 4.1 积分规则

| 来源 | 数额 | 说明 |
|---|---|---|
| 完成冒险事件 | +1 / 次 | 与等级统计同口径（`recordStat` 每次调用 +1） |
| 晋升奖励 | 见等级表 reward | 黑羽+10、蓝羽+30、银羽+60、金羽+120、赤羽+200、白羽+400 |

### 4.2 实现位置

- 存储：`statsData.guildPoints`（随存档整体保存/导入/服务器加载）
- 事件积分：`recordStat()` 内 `statsData.guildPoints = (statsData.guildPoints || 0) + 1`
- 晋升奖励：`checkRankUp()` 读取 `RANK_LEVELS[idx].reward`（数据驱动，调整数值只改数据表）
- 公会面板同步：`recordStat()` 中若公会视图可见则调用 `renderGuild()` 实时刷新

### 4.3 边界与兼容

- **旧存档**：无 `guildPoints` 字段 → 读取时按 0 处理，不报错
- **清空统计**（营地 → 清空统计数据）：事件数与积分一并归零（同 `statsData` 生命周期）
- **积分用途**：暂未开放消耗（积分商店占位界面已预留）

## 五、存档兼容说明

等级与积分全部挂在 `statsData`（`{ total, groups, guildPoints }`），
随现有存档机制自动持久化：
- 服务器自动保存（30 秒 + 事件后）→ `api/north/save`
- 手动导出/导入（JSON 文件）
- 存档加载/导入后调用 `updateRankUI()` 恢复头衔显示

`charData[].rank` 字段（角色卡原等级字段）**保留不动**，与新的全局冒险者等级互不干扰。
