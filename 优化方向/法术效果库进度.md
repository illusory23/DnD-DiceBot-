# 法术效果库 — 进度记录与分析

> 项目：尘封之卷 · 跑团平台 | 起始：2026-08-31
> 目标：跑团过程中使用法术时，效果自动生效（每个法术登记专属效果与词条）

---

## 一、总体设计

```
spell-effects.js（效果库数据）
    │
    ├─ kind: damage    → 攻击流程：命中后自动用词条 expr 掷伤害（含攻击加值）
    ├─ kind: heal      → 治疗流程：自动用词条 expr 掷治疗
    ├─ kind: temp_hp   → 治疗流程：掷 expr / 用 fixed，确认结算改为设置临时生命
    └─ kind: fn        → 专属效果函数（map.js 注册，攻击命中后自动调用）
                         例：吸血鬼之触 → 命中后按实际伤害自动回血

未登记法术 → 保持原手动流程（描述正则提取/手动表达式），不阻塞
```

效果条目结构：
```js
'火球术': { kind:'damage', expr:'8d6', dmgType:'火焰', save:'敏捷', desc:'8d6 火焰伤害（敏捷豁免减半）' }
'医疗术': { kind:'heal', fixed:70, desc:'恢复 70 点生命值' }
'虚假生命': { kind:'temp_hp', expr:'1d4+4', desc:'获得 1d4+4 点临时生命值' }
```

## 三、已知边界与取舍

| 项 | 当前行为 | 说明 |
|---|---|---|
| 伤害豁免 | 仅展示（desc），攻击仍走命中判定 | 豁免自动判定归第二/三期；火球术等豁免类法术暂用命中判定 |
| 施法属性调整值 | 治疗表达式用 +3 占位（如 1d8+3） | 弹窗内可手动修改为实际调整值；自动带入归后续 |
| 升环施法 | 不自动（表达式为基准环） | 弹窗可手动改 |
| 多目标 | 不自动（治疗祷言等至多 6 名） | 需逐目标使用 |
| 数值基准 | 玩家手册（PHB）经典数值 | 2024 版词条数值不同（如闪电束 3d8），以 PHB 为准 |
| 译名变体 | 效果库用词条名；CHM/SRD 译名差异靠 isHealSpell 关键词兜底 | 后续可加别名映射 |

## 四、扩展指引（新法术效果登记）

1. 在 `spell-effects.js` 的 `T` 表添加条目（kind/expr|fixed/desc）
2. 需要专属函数时：kind:'fn' + 在 map.js 注册 `e.fn = 你的函数`
3. 攻击流程自动生效（damage/fn）；治疗与临时生命在治疗弹窗自动生效（heal/temp_hp）
4. 大量新增可先用 `web/_extract_spell_effects.py` 提取草稿再人工核对
