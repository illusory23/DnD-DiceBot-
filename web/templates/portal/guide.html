📖 新手使用指南

← 返回首页
🚀 快速开始▶

第一步：注册账号

在首页右上角点击「登录」，切换到注册页填写用户名（2-30 字符，中英文数字均可）、邮箱与密码（9 位以上，须含英文与数字）。注册后自动登录，可上传圆形头像、编辑个人资料。

第二步：加入跑团房间

打开任意跑团工具页（如 3D 掷骰 或 战术地图），在弹出的加入覆盖层中输入你的 ID、选择颜色与身份：

身份能力
👑 DM（主持人）地图编辑、战争迷雾、暗骰、战斗管理、发布事件
🎭 PL（玩家）参与掷骰与聊天、查看地图与战斗（只读）、角色操作
💡 首个加入房间的用户自动成为 DM；DM 离开后，最早加入的剩余用户自动晋升。身份在本次会话中锁定，刷新页面不改变；更换身份需重开浏览器重新加入。

第三步：开始跑团

创建或导入角色卡 → 在 3D 掷骰页进行检定/豁免 → 在战术地图摆 token 与迷雾 → 用战斗面板管理先攻与伤害。所有页面通过 WebSocket 实时同步，队友能看到你的掷骰结果与地图操作。

❄️ 探索北境玩法▶

从首页「探索北境」入口进入独立生存冒险：在冰霜废土中探索、生存、战斗与采集。首次进入创建冒险者（可在公会中修改冒险者名），选择或快速创建角色卡。

🧭 事件探索

  • 四个事件按钮：🔍 探索雪原（调查/深入）、🎯 搜索资源、🌿 环境观察、🐺 生物遭遇

❓ 常见问题（FAQ）▶

Q：身份选错了想换 DM/PL 怎么办？

身份在本次浏览器会话中锁定。关闭全部页面重新打开浏览器，重新加入房间时选择新身份即可。

Q：同一 ID 别人用不了怎么办？

同一 ID 同一时间仅一人可用；对方 10 秒无心跳自动离线释放 ID。如果你自己刷新页面，同 IP 自动放行不会锁自己。

Q：我的地图/角色/北境数据会丢吗？

角色卡、战斗状态、聊天、北境存档均存储在服务器数据库（登录后），换设备可恢复；地图提供本地 IndexedDB + 服务器存档槽双保险，建议定期用「存档」槽命名保存。

Q：看不到战争迷雾下的内容？

迷雾对 PL 完全不透明是设计如此（防止偷看）。只有 DM 能绘制/擦除迷雾并透视下方内容。

Q：队友看不到我的掷骰？

确认双方都在同一房间（同一台服务器），且你是普通掷骰而非暗骰（暗骰仅自己可见）。掷骰经 WebSocket 实时广播，网络慢时略有延迟属正常。

Q：法术书添加法术报错？

请确认已选择角色后再添加；若持续报错可刷新页面（Ctrl+F5 强制刷新清缓存）后重试，并查看服务器日志。

Q：好友申请在哪里处理？

「用户中心 → 我的好友」卡片中：收到的申请可直接接受/拒绝，已发送的申请显示等待状态；也可点消息通知中的 🤝 通知跳转。
