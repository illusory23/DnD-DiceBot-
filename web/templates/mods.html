📁 Mod 存放路径：
mods/

📋 Mod 开发格式说明

目录结构：

mods/
└── your-mod/
    ├── mod.json          ← Mod元数据
    └── backend/
        ├── __init__.py
        └── router.py     ← 注册函数: def register(app, mod_id, mod_info)

mod.json 格式：

{
  "id": "my-mod",
  "name": "我的Mod",
  "version": "1.0.0",
  "description": "Mod描述",
  "author": "作者",
  "backend": {
    "enabled": true,
    "router": "backend.router:register"
  }
}
