局域网跑团平台搭建指南
═══════════════════════════════════════════════════════════════

使用 Web 版 DND5E 骰娘搭建局域网/远程跑团平台，让 DM 和玩家
通过浏览器各自操作。支持局域网直连和 FRP 内网穿透远程连接。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第一步：启动服务器
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在主机（DM 的电脑）上打开命令行：

  cd D:\游戏\尘封之卷-九子的注视\骰娘
  python dnd_bot.py --web

启动后服务运行在端口 5000：

  HTTP 页面 + API:  http://0.0.0.0:5000
  WebSocket 实时同步: ws://主机IP:5000/ws（与 HTTP 共用端口）

记下本机局域网 IP，玩家用这个访问。

查看本机 IP：命令行执行 ipconfig，找到"IPv4 地址"（如 192.168.1.14）


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第二步：确保防火墙放行
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

仅需放行端口 5000（WebSocket 与 HTTP 共用同一端口）：

方式一（推荐）：
  首次启动时 Windows 弹出防火墙提示 → 点击"允许访问"

方式二（手动添加规则）：
  1. 打开 Windows 安全中心 → 防火墙和网络保护 → 高级设置
  2. 左侧选择"入站规则" → 右侧"新建规则"
  3. 规则类型：端口 → 下一步
  4. TCP，特定本地端口填 5000 → 下一步
  5. 允许连接 → 下一步 → 全部勾选 → 下一步
  6. 名称填 DND Dice Bot → 完成


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第三步：其他玩家连接
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

让每个玩家在浏览器（手机 / 平板 / 电脑均可）输入：

  http://192.168.1.14:5000

（IP 地址换成第一步查到的 192.168.x.x）

注意：所有设备必须连接同一个 WiFi / 局域网。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第四步：加入房间并选择身份
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

打开页面后会看到"欢迎来到 DND5E 骰娘"加入覆盖层：

  1. 输入你的玩家 ID（不可与在线玩家重复）
  2. 选择 ID 颜色（可选）
  3. 选择身份：👑 DM（主持人）或 🎭 PL（玩家）
  4. 点击"🚪 进入骰娘"

身份一旦选择，在本次会话中永久锁定。切换页面/刷新不会改变身份。
如需更换身份，需重新打开浏览器连接骰娘。

只有第一个选择 DM 身份的用户成为主持人，后续选择 DM 的用户
自动降级为 PL。

第六步：地图页面 (/map) — 核心协作功能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

这是最重要的页面，DM 和 PL 在这里共享战术地图。

【实时同步（自动，无需手动操作）】
  所有用户进入地图页面后自动连接共享画布。
  DM 的每一笔涂画、标记拖放、文字添加都会实时同步给所有在线 PL。
  PL 的操作也会同步给其他人。
  同步方式：WebSocket（ws://主机:5000/ws，与 HTTP 共用端口）

【DM 专属功能】
  · 📤 推送按钮：将当前画布完整状态（含地图图层）写入服务端持久化
  · 🌫 战争迷雾：绘制/删除迷雾区域，DM 视角半透明可看穿
  · 🗑 清除涂画：清除所有涂画和文字
  · 💣 全部清除：清除全部内容（含地图和标记）

【PL 限制】
  · 🔄 同步按钮：从服务端拉取完整画布状态（手动备用）
  · 迷雾完全不透明（实心灰色），无法看到下方任何内容
  · 不可使用战争迷雾/清除涂画/全部清除功能
  · 战斗面板只读

【图层系统】
  · 导入地图图片（🖼 导入按钮）
  · 多图层管理：显示/隐藏、缩放、移动、重命名、删除
  · 图层 dataURL 存储在服务端共享画布，PL 通过 URL 按需加载

【标记与文字】
  · 从角色侧边栏拖放标记到地图
  · 文字工具（T）添加标注
  · 标记/文字增删拖实时广播给所有用户

【存档系统】
  · 💾 多存档槽位，本地 IndexedDB 存储
  · 定时自动保存（每 3 秒）+ 页面离开时保存
  · 刷新页面后自动恢复

【底部骰子栏】
  · 快捷掷骰：d20/优势/劣势/d6/d8/3d6/4d6k3/察觉/隐匿
  · 不打断地图操作

推荐跑团流程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一、准备阶段（DM）

  1. 打开 /character → 为每个 PC 创建角色或从 Excel 导入
     （也可让玩家自行在浏览器中创建角色）

  2. 打开 /map → 🖼 导入地图 → 导入地城/区域地图图片

  3. 点击 📤 推送按钮，将地图写入服务端共享画布
     （PL 之后可通过 🔄 同步按钮拉取）

  4. 打开 /combat → 战斗追踪器准备就绪

  5. 可用 /reference 预查本次可能遭遇的怪物

二、游戏进行中

  · DM 在地图页：
      - 用画笔工具标注区域、圈出重点
      - 用文字工具添加地点名称
      - 从角色侧边栏拖放角色标记到地图上
      - 绘制战争迷雾隐藏未探索区域
      - 所有操作自动实时同步给 PL

  · PL 在地图页：
      - 实时看到 DM 的涂画和标记更新
      - 迷雾区域完全不透明，无法看到下方内容
      - 点击 🔄 同步按钮手动刷新（备用）

  · 玩家在掷骰页做检定：
      输入"察觉" → 选择优势/劣势 → 点击检定
      或使用快捷按钮一键检定

  · 遭遇战斗时（DM 操作）：
      1. 战斗页 → 从角色卡下拉框选择 PC → 自动填充数据
      2. 资料库搜索怪物（如"地精"）→ 查看数据 → 加入战斗
      3. 点击"开始战斗" → 先攻自动排序
      4. 逐回合点"下一回合"
      5. 伤害/治疗从下拉框选目标 → 输入数值 → 应用

  · 地图页底部骰子栏可快速掷骰，无需切换页面

  · 左侧聊天面板：DM 和 PL 实时文字交流

三、收尾

  DM 在命令行中执行：
    .log
  导出本次跑团完整记录（含目录/收获总结/详细事件）为 TXT 文件
  保存在 ./跑团记录/ 目录下

玩家设备要求
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  · 任何能上网的设备均可：手机、平板、笔记本
  · 支持浏览器：Chrome / Edge / Safari / Firefox
  · 无需安装任何 App，打开浏览器输入地址即可

公网访问（FRP 内网穿透）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果玩家不在同一局域网，使用樱花 FRP 等内网穿透工具：

  1. 在樱花 FRP 控制台创建隧道，映射到本地 5000 端口
     （仅需一个端口：HTTP + WebSocket 共用 5000）

  2. 在 DM 电脑运行 frpc 客户端

  3. 玩家通过 FRP 公网地址访问：
     http://frp-地址:端口/map

  4. WebSocket 自动使用同一隧道（/ws 路径），无需额外配置

  注意：
  · FRP 只需穿透一个端口（5000）
  · 公网访问建议仅在跑团时段开放
  · 远程 PL 的身份判定按加入时选择的身份为准

数据持久化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  服务端重启后共享画布自动恢复：
    保存位置：web/shared_canvas.json
    每次编辑后 3 秒自动保存

  角色数据：
    保存位置：data/characters.db（SQLite）
    重启不丢失

  地图存档：
    保存位置：浏览器 IndexedDB（本地）
    刷新页面自动恢复
