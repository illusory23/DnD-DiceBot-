局域网跑团平台搭建步骤
═══════════════════════════════════════════════════════════════

使用 Web 版 DND5E 骰娘搭建局域网跑团平台，让 DM 和玩家在同
一 WiFi 下通过浏览器各自操作。


第一步：启动服务器
───────────────────────────────────────────────────────────────

在主机（DM 的电脑）上打开命令行：

  cd D:\游戏\尘封之卷-九子的注视\骰娘
  python dnd_bot.py --web

启动后会显示：

  * Running on http://127.0.0.1:5000        ← 本机访问地址
  * Running on http://192.168.1.14:5000     ← 局域网地址（玩家用这个）

记下 192.168.x.x:5000 这个地址，后面发给玩家。


第二步：确保防火墙放行
───────────────────────────────────────────────────────────────

Windows 防火墙可能会阻止外部访问端口 5000。两种方式放行：

方式一（推荐）：
  首次启动时 Windows 弹出防火墙提示 → 点击"允许访问"

方式二（手动添加规则）：
  1. 打开 Windows 安全中心 → 防火墙和网络保护 → 高级设置
  2. 左侧选择"入站规则" → 右侧"新建规则"
  3. 规则类型：端口 → 下一步
  4. TCP，特定本地端口填 5000 → 下一步
  5. 允许连接 → 下一步 → 全部勾选 → 下一步
  6. 名称填 DND Dice Bot → 完成


第三步：其他玩家连接
───────────────────────────────────────────────────────────────

让每个玩家在浏览器（手机 / 平板 / 电脑均可）输入：

  http://192.168.1.14:5000

（IP 地址换成第一步实际显示的 192.168.x.x）

注意：所有设备必须连接同一个 WiFi / 局域网。


第四步：各页面分工
───────────────────────────────────────────────────────────────

┌────────────┬──────────┬──────────────────────────────┐
│   页面     │  使用者  │          用途                │
├────────────┼──────────┼──────────────────────────────┤
│ 掷骰 /     │ 所有人   │ 掷骰、检定、属性生成        │
│ 角色卡     │ 所有人   │ 创建/管理自己的角色卡        │
│ /character│          │ 从 Excel 导入、设置属性/装备  │
│ 战斗       │ DM       │ 管理先攻顺序、处理伤害/治疗  │
│ /combat    │          │ 从角色卡导入参战者            │
│            │          │ 从资料库搜索怪物加入战斗      │
│ 地图 /map  │ DM       │ 导入地图图片                 │
│            │          │ 画笔涂画、文字标注            │
│            │          │ 放置角色头像标记              │
│            │          │ 底部快速掷骰栏               │
│ 参考       │ 所有人   │ 查询法术/怪物/规则/状态      │
│ /reference│          │ 五版不全书 CHM 资料库         │
└────────────┴──────────┴──────────────────────────────┘


推荐跑团流程
───────────────────────────────────────────────────────────────

一、准备阶段（DM）

  1. 打开 /character → 为每个 PC 从 Excel 导入角色卡
     （或让玩家自己通过浏览器访问后创建角色）

  2. 打开 /map → 点击"导入地图"加载地城/区域地图
     地图支持 jpg/png 等常见图片格式

  3. 打开 /combat → 战斗追踪器准备就绪

  4. 角色卡页面的"资料库查询生物"可预查本次可能遭遇的怪物


二、游戏进行中

  · DM 在地图页用画笔工具标注区域、圈出重点
    用文字工具添加地点名称
    从角色侧边栏拖放角色标记到地图上

  · 玩家在掷骰页做检定：
      输入"察觉" → 选择优势/劣势 → 点击检定
      或使用快捷按钮一键检定

  · 遭遇战斗时（DM 操作）：
      1. 战斗页 → 从角色卡下拉框选择 PC → 自动填充数据
      2. 资料库搜索怪物（如"地精"）→ 查看数据 → 加入战斗
      3. 点击"开始战斗" → 先攻自动排序
      4. 逐回合点"下一回合"
      5. 伤害/治疗从下拉框选目标 → 输入数值 → 应用

  · 地图页底部掷骰栏可快速投掷 d20、优势/劣势、察觉/隐匿
    不打断地图操作，无需切换页面


三、收尾

  DM 在命令行中执行：
    .log
  导出本次跑团完整记录（含目录/收获总结/详细事件）为 TXT 文件
  保存在 ./跑团记录/ 目录下


玩家设备要求
───────────────────────────────────────────────────────────────

  · 任何能上网的设备均可：手机、平板、笔记本
  · 支持浏览器：Chrome / Edge / Safari / Firefox
  · 无需安装任何 App，打开浏览器输入地址即可


可选优化
───────────────────────────────────────────────────────────────

  · 把局域网地址发到微信群/QQ群，点链接直接打开
  · 用二维码生成器把 http://192.168.x.x:5000 生成二维码
    打印出来放桌上给玩家扫
  · DM 建议用大屏设备（笔记本/台式机+双屏），
    一个屏幕显示地图，另一个管理战斗和掷骰


公网访问（高级）
───────────────────────────────────────────────────────────────

如果玩家不在同一局域网，需要内网穿透：

  方法一：ngrok（最简单，免费有限制）
    1. 下载 ngrok：https://ngrok.com
    2. 注册获取 authtoken
    3. 运行：ngrok http 5000
    4. 获得公网地址如 https://xxx.ngrok.io

  方法二：frp（自建，需要公网服务器）
    1. 在公网服务器部署 frps
    2. 在 DM 电脑部署 frpc，映射 5000 端口
    3. 详见 frp 官方文档

  注意：公网访问有安全风险，建议设置访问密码或仅在跑团时段开放
