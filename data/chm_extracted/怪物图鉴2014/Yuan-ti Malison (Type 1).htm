恶咒蛇人（1 型）Yuan-ti Malison (Type 1)
中型怪兽（变形生物、蛇人），绝对中立
AC 12
HP 66（12d8 + 12）
速度 30尺
力量16 敏捷14 体质13 智力14 感知12 魅力16
技能：欺诈+5，隐匿+4
伤害免疫：毒素
状态免疫：中毒
感官：黑暗视觉 60 尺；被动察觉11
语言：深渊语，通用语，龙语
CR 3
【特性】
变形生物：蛇人用一个动作变形为一头中型蛇Medium snake，或以该动作变回其真实形态。他的所有资料均不会发生改变，其随身着装和携带的装备也不会随变形发生变化。蛇人死亡时将恢复其真实形态。
魔法抗性：原体蛇人在对抗法术和其他魔法效果的豁免检定上具有优势。
恶咒类型：原体蛇人有以下几种类型： list list-hang-notitle Type 1: 类型1： item 蛇首人身 Type 2: 类型2： item 人类的头和身体，但有着蛇般的双臂 Type 3: 类型3： item 人类的头和上半身，下半身则由蛇尾取代双脚
【动作】
多重攻击 (仅蛇人型态)：蛇人发动两次远程攻击或两次近战攻击，但每次只能使用一次啃咬攻击。
啃咬：mw 命中5，触及5尺，单一生物。 5（1d4 + 3）点穿刺伤害加上7（2d6）点毒素伤害。
弯刀 (仅蛇人型态)：mw 命中5，触及5尺，单一目标。6（1d6 + 3）点挥砍伤害。
长弓 (仅蛇人型态)：rw 命中4，射程150/600尺，单一目标。6（1d8 + 2）点穿刺伤害加上7（2d6）点毒素伤害。
