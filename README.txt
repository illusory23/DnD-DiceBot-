================================================================================
  1. 项目概述
================================================================================

尘封之卷是一个面向 D&D 5E 规则的线上跑团辅助平台，提供三大核心体验：

  - 跑团工具平台：3D 掷骰、角色卡管理、战斗追踪、法术/怪物查询、聊天室
  - 官网门户：项目展示、用户系统、功能导航、视频背景
  - 北境雪原：基于"九子的注视"世界观的探索生存玩法，可独立运行

================================================================================
  3. 技术架构
================================================================================

  后端：Python 3 + Flask
    - web/app.py              Flask 主应用，路由注册
    - core/                   核心引擎（骰子、角色、D&D 规则）
    - utils/                  工具（数据加载、CHM 搜索、Excel 导入）
    - dnd_bot.py              QQ 机器人指令适配 + 事件表定义

  前端：原生 HTML/CSS/JS（无框架依赖）
    - 3D 掷骰                @3d-dice/dice-box (Three.js 物理引擎)
    - 确定性骰子引擎         自定义 Three.js 同步骰子系统
    - 雪地特效               Canvas 雪花 + 极光粒子
    - 事件驱动               原生事件委托

  数据：
    - SQLite (characters.db)  角色持久化
    - JSON                    法术库、怪物库、物品表
    - CHM 索引                离线 D&D 规则检索
    - TXT                     随机事件表定义

================================================================================
  7. 北境雪原 — 核心玩法
================================================================================

7.1  概述
  以北境"九子的注视"为背景的独立探索生存玩法。玩家在极寒雪原中
  探索、采集、战斗、生存，体验完整的 D&D 5E 规则 + 生存机制。

7.2  事件系统（15 张表，完整 CHAIN 链式调用）
  主事件表          探索(ts100)、调查(dc100)、遭遇(zy100)
  环境与遭遇        环境(hj6)、特殊事件(sj6)、人类(rl100)、野兽(ys10)
  生物              非敌对(zl12)、特殊生物(sw100)
  资源              材料(cl50)、特殊材料(cl100)、矿物(kw100)、发现(fx100)
  探索              遗迹(yj8)、全随机(qsj100)
  查询              物品表(wp)

7.3  生存机制
  ❄️ 严寒    — 每 3 次事件体质豁免，DC 基础 12，最高 3 级
  🍖 口粮    — 每 4 次事件消耗 1 份，断粮后体质劣势 + 掉血
  🧭 迷失    — 每 5 次事件感知检定，迷失后继续深入/返回无效
  👻 恶霜    — 每事件生存 DC15 辨别，失败 1d4 伤害，长休解除
  🔥 火源    — 每份燃料 2 次事件照明，暴风雪中限特定燃料

7.4  检定交互
  所有 DC 检定均支持 3D 掷骰按钮，包括：
  - 单步检定（如采集资源 DC12）
  - 多步检定（如雪坑：被动察觉→敏捷豁免→运动爬出）
  - 失败额外步骤（雪坑/雪崩失败后的运动 DC 爬出）
  - 纯效果条目（极光、迷失等无 DC 效果）

7.5  营地系统
  ⛺ 角色管理    — 多角色选择/新建/删除
  🛌 长休/短休   — 确认弹窗 + 时间推进（短休1h/长休8h）
  📖 冒险者手札  — 中世纪羊皮手札（封面+内页背景图），生存法则/冒险记录/笔记/馈赠/生物图鉴
  ⚒️ 工作间      — 制作台/铁砧/熔炼炉/炼药锅（四合一生产系统 + 背包牛皮内衬UI）
  📦 营地仓库    — 独立存储空间，数量弹窗存取，10列+6列双面板
  🧑‍🤝‍🧑 补给站  — 商店界面（UI就绪，待上架商品）
  ⚒️ 铁匠工房    — 锻造界面（UI就绪，待开放）
  🧪 炼金工坊    — 炼金界面（UI就绪，待开放）
  💾 存档系统    — JSON 导出/导入（含仓库+时间+工作间+配方解锁完整状态）

7.6  合成/熔炼配方
  制作台：火把、网兜、长柄网兜、驱寒药膏
  熔炼炉：铜→铜锭、铁→铁锭、寒铁→寒铁锭、银→银锭、金→金锭
  炼药锅：治疗药水(2d4+2)
  铁砧：待开放

7.7  燃料系统
  松枝 / 松脂 / 铁松松脂(×2) / 荧光苔 / 柴火/石块
  暴风雪中仅荧光苔和铁松松脂可用
  煤矿不计入燃料（仅可出售/熔炼燃料）

7.8  时间系统
  初始时间：上午5:00
  推进规则：每次事件+1h（链式事件只计1次），短休+1h，长休+8h
  昼夜判定：21:00-5:00夜晚🌙，其余白天☀️
  切换提示：暗调金边弹窗，2.5秒自动消失

================================================================================
  9. 事件表系统
================================================================================

  事件表定义在三处保持同步：
    1. north-expedition.html    JavaScript TABLES 对象（前端渲染用）
    2. dnd_bot.py               Python 字典（QQ 机器人用）
    3. data/随机事件表.txt       文字版参考文档

  链式调用机制：
    顶层表 → 子表 → 叶子表（产生实际效果）
    如：全随机(qsj100) → 探索(ts100) → 采集资源 → 材料(cl50) → 获取物品

  效果触发层级：
    ITEM_ACTIONS      — 自动拾取（材料/矿物表）
    CHECK_ACTIONS     — 检定交互（DC 检定 + 3D 掷骰按钮）
    LINK_RULES        — 联动规则（猎人小屋/温泉/岩洞等）
    敌对战斗/逃离按钮  — 野兽/敌对生物遭遇
    喂食交互          — 友善生物


================================================================================
  10. 开发指南
================================================================================

10.1  添加新事件表条目
  1. 在 north-expedition.html 的 TABLES 对象中添加条目
  2. 如需检定交互，在 CHECK_ACTIONS 中添加 steps 定义
  3. 如需自动拾取，在 ITEM_ACTIONS 中添加 ranges
  4. 同步更新 dnd_bot.py 中的对应 Python 字典
  5. 同步更新 data/随机事件表.txt

10.2  CHECK_ACTIONS step 格式
  {
    label:    '步骤标签',        // 必填
    ability:  'str|dex|con|int|wis|cha', // 属性
    skill:    '技能名',          // 可选，技能检定
    save:     true,              // 可选，豁免检定
    passive:  true,              // 可选，被动检定(d20=10)
    dc:       15,                // DC 值
    damage:   '1d6',             // 可选，失败伤害
    passMsg:  '通过消息',
    failMsg:  '失败消息',
    passDone: true,              // 通过后结束检定
    failDone: true,              // 失败后结束检定
    passEffect: fn,              // 可选，通过后执行
    failEffect: fn,              // 可选，失败后执行
    failExtra: {...}             // 可选，失败后额外步骤
  }

10.3  3D 骰子集成
  dice-bridge.js 提供 window.roll3DDice(notation) 接口
  支持玩家取消 → 回退为文本掷骰
  自动降级：3D 不可用时使用随机数
