# 🎲 骰娘 → 远程多人跑团平台 改造分析

## 当前状态

骰娘目前是一个**单用户 Web 应用**：
- Flask HTTP 服务器，无 WebSocket
- 无用户系统，所有人共享同一个角色数据库
- 无实时同步，需要手动刷新
- 战斗追踪、角色数据存储在服务端 SQLite 中
- 支持 `--lan` 局域网多设备访问

## 与 FVTT/枭熊的差距

| 功能维度 | 当前骰娘 | FVTT/枭熊 | 差距 |
|---------|---------|-----------|------|
| 访问方式 | 局域网 HTTP | 公网/内网穿透 | 需要穿透方案 |
| 多人协作 | 共享页面无隔离 | 多用户+权限 | 需要用户系统 |
| 实时同步 | 无（需刷新） | WebSocket 推送 | 需要 WebSocket |
| 战斗地图 | ❌ | ✅ 地图+Token | 需要地图引擎 |
|  Fog of War | ❌ | ✅ | 需要地图引擎 |
| 文件共享 | ❌ | ✅ 图鉴/文档 | 需要文件系统 |
| 聊天系统 | 命令输入 | ✅ 独立聊天 | 需要聊天系统 |
| 音乐播放 | ❌ | ✅ BGM | 可选 |
| 角色归属 | 无主 | 玩家绑定角色 | 需要用户系统 |

## 改造方案：分三个阶段

### 阶段一：内网穿透 + 基础远程（1-2天）

**目标**：让外网玩家能访问骰娘，DM 主持游戏

#### 1.1 内网穿透方案

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **ZeroTier** | 免费、P2P 低延迟、虚拟局域网 | 每人需装客户端 | ⭐⭐⭐⭐⭐ |
| **Tailscale** | 同上，更易用 | 同上 | ⭐⭐⭐⭐⭐ |
| **frp** | 自建服务器、灵活 | 需要公网服务器 | ⭐⭐⭐⭐ |
| **ngrok** | 无需安装客户端 | 免费版限制多 | ⭐⭐⭐ |
| **Cloudflare Tunnel** | 免费、稳定 | 需要域名 | ⭐⭐⭐⭐ |

**推荐**：ZeroTier（最像"局域网"，骰娘 `--lan` 模式直接用）

#### 1.2 ZeroTier 操作步骤

```
DM端：
1. 注册 ZeroTier (zerotier.com)，创建网络
2. 所有参与者安装 ZeroTier 客户端
3. 加入同一个网络 ID
4. DM 启动骰娘: python dnd_bot_pe.py --lan
5. 玩家浏览器打开: http://[ZeroTier分配的DM虚拟IP]:5000

无需修改骰娘任何代码！
```

#### 1.3 此阶段的局限

- ⚠️ 所有人看到相同界面（无角色隔离）
- ⚠️ 玩家可能误操作他人角色
- ⚠️ 无实时通知（骰子结果需手动分享屏幕/口述）
- ⚠️ 需要额外语音工具（QQ/微信/ Discord）

### 阶段二：多人协作改造（1-2周开发）

**目标**：支持 DM + 多名玩家，各自有角色和视角

#### 2.1 需要新增的功能模块

```
骰娘/
├── core/
│   ├── user.py          ← 新增：用户管理
│   ├── session.py       ← 新增：房间/会话管理
│   └── websocket.py     ← 新增：实时通信
├── web/
│   ├── templates/
│   │   ├── dm.html      ← 新增：DM 视角页面
│   │   └── player.html  ← 新增：玩家视角页面
│   └── static/
│       └── chat.js       ← 新增：聊天+骰子广播
```

#### 2.2 具体功能清单

**用户系统**
```
- 注册/登录（简易密码或邀请码）
- 角色：DM（主持人）、Player（玩家）、Observer（旁观）
- DM 可踢人、禁言
- 玩家绑定到自己的角色卡
```

**房间系统**
```
- DM 创建房间 → 生成邀请码/链接
- 玩家通过邀请码加入
- 一个房间 = 一次跑团会话
- 房间内共享：战斗追踪、骰子日志、聊天记录
```

**实时骰子广播** ⭐ 核心体验
```
- 玩家掷骰 → 广播给房间所有人
- 格式："[艾琳] 🎲 察觉检定: d20(15)+3 = 18"
- DM 可暗骰（只有自己看到）
- 骰子历史记录（可回溯）
```

**聊天系统**
```
- 公共频道（所有人可见）
- 私聊（DM ↔ 玩家）
- 骰子结果嵌入聊天
- 支持简单的 Markdown
```

**角色归属**
```
- 每个玩家只能操作自己的角色
- DM 可以操作所有角色和 NPC
- 角色列表按玩家分组显示
```

#### 2.3 技术实现

```
依赖新增：
- flask-socketio    # WebSocket 支持
- flask-login       # 用户会话管理
- sqlite3           # 已有，新增 users 表

新增数据表：
users:         id, username, password_hash, role, created_at
rooms:         id, name, dm_user_id, invite_code, created_at, is_active
room_members:  room_id, user_id, role, joined_at
chat_messages: id, room_id, user_id, type(text/dice/system), content, created_at
dice_log:      id, room_id, user_id, character_id, expression, result, is_private
```

### 阶段三：完整 VTT 平台（1-2月开发）

**目标**：对标 FVTT/枭熊，具备战斗地图等完整功能

#### 3.1 战斗地图系统

```
技术选型：
- Canvas/SVG 渲染（推荐 Canvas）
- 图层系统：地图层 → Token层 → FoW层 → 特效层
- 网格系统：方形/六边形网格

功能：
- 上传地图图片（支持大图缩放）
- 放置 Token（角色/NPC/怪物）
- 拖拽移动 Token
- 网格吸附
- 测量距离/范围
- Fog of War（战争迷雾）
  - DM 手动擦除
  - 基于 Token 视野自动计算
- 区域标记（AOEs、范围法术）
- 光源/视野系统
```

#### 3.2 文件/资料共享

```
- 图片共享（NPC肖像、场景图、地图）
- PDF 规则书在线查看
- DM 笔记/剧情摘要（可选择性发给玩家）
- 道具/魔法物品展示卡片
```

#### 3.3 其他 VTT 功能

```
- 背景音乐/音效播放
- 骰子 3D 动画
- 一键导入 D&D Beyond/其他平台角色
- 跑团录像/回放
- 自定义宏命令
```

## 立即可做 vs 需要开发

### 🟢 今天就能用的（零代码改动）

```
1. 安装 ZeroTier → 创建网络 → 所有人加入
2. DM 运行: python dnd_bot_pe.py --lan
3. 玩家浏览器打开 DM 的 ZeroTier IP:5000
4. 配合 QQ语音/微信电话 使用
5. 所有人通过命令输入操作骰娘
```

**能用但不完美**：所有人共享界面，需要 DM 口头协调"现在轮到谁了"

### 🟡 最小可行改造（2-3天开发）

```
1. 添加简易"暗骰"功能
   - .r 公开      → 所有人可见
   - .r .dm 3d6   → 仅 DM 可见

2. 添加骰子日志自动刷新
   - 每3秒轮询新结果
   - 简单但有效

3. 添加"当前发言人"标记
   - DM 点击角色名 → 显示"轮到XX操作"

4. 角色数据按设备IP简单隔离
   - 已有 _active_chars[ip] 按IP区分
```

### 🔴 完整多人改造（2-4周开发）

按照阶段二的规划，新增用户系统、房间系统、WebSocket 实时同步、聊天系统。
