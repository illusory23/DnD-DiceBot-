# 法术书模块

## 文件与职责

- `web/templates/spells.html`（约 514 行）：**无独立 JS 文件，全部逻辑内联**（约 184-496 行）。已学习法术列表、已准备法术、手动添加、资料库搜索、法术详情弹窗
- `core/character.py`：`add_learned_spell` / `remove_learned_spell` / `get_learned_spells` / `clear_learned_spells`（约 773-801 行），`add_prepared_spell` / `remove_prepared_spell` 等
- `core/models.py`：`LearnedSpell`（learned_spells 表）、`PreparedSpell`、`SpellSlot`
- `web/app.py`：法术书 API 在"法术书 API"区（约 1397-1471 行）；法术资料库 API（spells/search、spell-detail）
- 法术资料库数据：`data/spells_full.json`、`data/srd_spells.json`

## 功能

- **法术书（已学习法术）**：查看已学法术列表（名称/环阶/学派），点击查看详情，可删除
- **手动添加法术**：名称、环阶、学派、施法时间、距离、时长、成分、仪式、专注、描述
- **资料库搜索**：按名称搜索法术资料库，一键快速添加；点开详情可"添加到法术书（含详情）"（等级/学派/施法时间/距离/时长/成分/仪式/专注/描述/来源一并写入）
- **已准备法术**：从法术书选择或直接添加准备法术，可取消准备
- **法术位管理**：1-9 环每环显示 已用/最大，长休自动恢复

## 调用链

- 启动：`loadSpellCharSelect()` → 选择角色 `onSpellCharChange()` → `refreshAll()`（重取角色数据渲染 learned / prepared 列表）
- 资料库搜索：`doSpellSearch` → `quickAddLearned`（先 `GET /api/spell-detail/<name>` 取详情再添加）
- 统一添加入口：`doAddLearned(name, level, school, castingTime, range, duration, components, ritual, concentration, description, source)`——手动添加 `manualAddSpell` 与详情页"添加到法术书（含详情）" `addDetailedToLearned` 均走它
- 其他：`showLearnedDetail` / `prepareSpell` / `unprepareSpell` / `removeLearnedSpell`

## 关键 API

- `POST /api/character/<name_or_id>/learned-spell`：添加已学法术（body：name/level/school/casting_time/range/duration/components/ritual/concentration/description/source）
- `DELETE /api/character/<name_or_id>/learned-spell/<spell_id>`：删除
- `POST /api/character/<name_or_id>/prepared-spell`：从法术书选择或直接添加准备法术（仅 name/level）
- `DELETE .../prepared-spell/<spell_id>`：取消准备
- `PUT /api/character/<name_or_id>/spell-slots`：整体保存法术位 `{环阶: {used, max}}`
- 资料库：`GET /api/spells/search?q=`、`GET /api/spell-detail/<path:name>`、`GET /api/spell/<name>`

## 关键数据结构

- `learned_spells` 表列：id/character_id/spell_name/spell_level/school/casting_time/**range**/duration/components/ritual(默认'否')/concentration(默认'否')/description/source(默认'自定义')
- `prepared_spells`：spell_name/spell_level/is_prepared/notes
- `spell_slots`：`{环阶字符串: {max, used}}`——**键是字符串**（前端 `spellSlots[i] || spellSlots[String(i)]` 兼容）

## 修改注意点（已知坑）

- **`range` 参数名**：`add_learned_spell` 签名是 `range=`（Python 内置名，勿遮蔽勿加下划线）。曾因调用方误写 `range_=` 导致 500 + HTML 错误页（前端报 "Unexpected token '<'"）。改此链路时保持两处一致
- **详情面板描述渲染（v5.8 修复）**：`showLearnedDetail` 的描述为纯文本（CHM 提取含 \n），渲染必须 HTML 转义（& < >）+ `white-space:pre-wrap` 保留换行（`.sd-body` 的 pre-wrap 依赖 `.spell-detail-card` 父类，详情面板父级是 `.card` 不生效，需内联）；卡片勿加 `min-height:55vh`（描述短时撑出无效空白）
- **法术位 500 排查**：接口 500 时先看 server 日志/Flask 堆栈（默认错误日志只有"服务端错误"一行，无堆栈，可用 Flask test_client 复现）
- DND5E24 悲灵模板 Excel 导入的法术位解析优先级：G 列"已用/最大" → G 纯数字 → E 列（法术位数值），见 `utils/excel_importer.py` `_import_dnd5e24`；**J 列"法术值"是模板内置示例值（空白模板中即存在），一律忽略，勿再读取**（曾导致低等级角色被识别出 2/3/5/6/7/9/10/11/13 的高环法术位）
- 手动添加环位 `parseInt(...)||0` 保证 level 为数字；`data.get('level', 0)` 后端 `int()` 转换——前端勿传空字符串
