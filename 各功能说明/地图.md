# 地图战斗模块

## 文件与职责

- `web/templates/map.html`（约 1335 行）：战术地图页，内联 CSS + 大量 onclick 按钮；**第 1303-1307 行引用 5 个 JS，缓存版本号统一 `?v=60`**
- `web/static/map.js`（约 5300 行）：地图核心大文件。区块划分：
  - 聊天系统（1-139）→ 核心状态 `collectState`/`applyState`（140-505）→ 坐标/工具切换（506-648）→ 鼠标绘制/框选（649-1083）→ 文字框（1084-1167）→ token/隐私脱敏/网络序列化（1168-1661）→ 角色侧边栏（1662-1864）→ 图层（1865-2150）→ 迷雾/骰子/3D 攻击伤害治疗（2151-2966）→ 视图操作（2967-3194）→ **内嵌战斗面板 + 服务器同步**（3196-3761：`pushCombatState`/`syncCombatFromServer`/`applyRemoteCombatState`）→ **boot 启动**（3787-4344：`initSaveSystem` 四级回退）→ WS 协作（4345-4895）→ WS 安全包装/脏标记/远程合并（4896-5321）
- `web/static/map-fog.js`（约 330 行）：战争迷雾（`fogStrokes`/`fogErasures` 画笔涂抹/橡皮挖洞、`redrawFogCanvas` 离屏 mask、`isUnderFog` 遮盖检测、`floodFill`）
- `web/static/map-page.js`（约 90 行）：加入房间覆盖层（`doJoin`/心跳/颜色）、返回按钮、骰子统计面板
- `web/static/map-saves.js`（约 450 行）：存档槽系统、JSON 导出/导入、服务端存档
- `web/static/map-idb.js`（约 75 行）：IndexedDB 封装
- `web/static/combat.js`（约 500 行）：独立战斗页（先攻/伤害治疗/战斗状态持久化/WS 同步），combat.html 引用 `combat.js?v=29`
- `web/static/combat-monsters.js`（约 103 行）：怪物搜索/详情/加入战斗（2026-08-17 从 combat.js 拆分，顶层函数全局可见）
- `web/shared_state.py`（约 445 行）：服务端共享画布（PG `SharedCanvas` 单行表、单调 `_version`、防抖 3s/最长 15s 落盘、图层图片外置 `maps/layers/`、迷雾增量 `apply_fog_incremental`）

**加载顺序（map.html）**：map-idb → map-fog → map-saves → map.js → map-page.js，boot 启动立即调用迷雾/存档函数，**不可颠倒**。

## 功能

- **白板绘图**：画笔/形状绘制、框选移动、文字框，可随时清除
- **token**：放置角色/怪物 token，拖拽、旋转、按角色同步 HP；他人 token 头像与名称均可见，仅角色信息面板不可查看；DM 公开角色可见
- **战争迷雾**：画笔式涂抹遮蔽、橡皮像素级挖洞、洪水填充；DM 半透明 / PL 不透明；每笔雾与擦除轨迹独立 id/粗细，WS 增量同步
- **图层**：图片图层（外置存储到 `maps/layers/`），可切换显隐
- **内嵌战斗面板**：添加战斗者、先攻排序、回合轮转、伤害/治疗、状态标记；战斗中临时加入按先攻排队、本轮不插队；独立战斗页（combat.html）同套规则
- **伤害/治疗聊天室广播**：3D 攻击命中扣血、攻击未命中、3D 治疗回血、战斗面板手动伤害/治疗均自动向聊天室发送系统消息（"⚔️ xxx 受到 n 点伤害 / 🛡️ xxx 未被击中 / 💚 xxx 恢复 n 点血量"；**d20 自然 20 时切换为"💥 xxx 遭受重击，受到了 n 点伤害"**；`mapChatNotifyHp` → `/api/chat/send`，`rollAttackDice` 返回 `{total, isCrit}`）
- **3D 骰子**：攻击/伤害/治疗带 3D 掷骰动画，掷骰结果帧同步
- **存档**：本地四级回退（内存 `_unload` → `_light` ≤200KB → IndexedDB → 旧格式）+ 服务器存档槽（`跑团存档/地图/`）+ JSON 导出/导入
- **房间协作**：加入房间（DM/PL 身份）、WS 实时同步（画布/迷雾/战斗）、地图内聊天

## API 与 WS

- HTTP：`GET/POST /api/shared-canvas`（`since_ver` 增量）、`POST /api/shared-canvas/layer-image`、`GET /api/shared-canvas/layer/<id>`；`GET/POST /api/combat-state`（**409 版本冲突**）；`GET/POST /api/map-saves`、`GET/DELETE /api/map-saves/<name>`；`/api/room/join`、`/api/room/heartbeat`、`/api/dm-status`、`/api/dice-stats`
- WS `/ws` 消息：`init`（全量）、`sync`（对账）、`canvas_update`、`stroke`/`strokes_remove`/`strokes_clear`、`op`（layers/tokens/texts/fog 增量）、`clear_all`、`combat_update`、`combat_update_ack`（回执+服务器时间戳）、`combat_update_conflict`、`fog_incr`（雾笔/擦除按 id 增量）、`dice_roll*`

## 关键数据结构

- **战斗**：`{combatants:[{name, initiative, initDetail, hp, hpMax, ac, conditions[], charId, isCurrent, joinedLate, addedBy, addedByRole}], round, _ts, started}`；localStorage `dnd_combat_state`（map.js 与 combat.js 共用）；服务端 PG `combat_state` 表
- **迷雾**：`fogStrokes`/`fogErasures`（每笔带 id/width/radius）/`fogVisible`；同步格式 `{strokes, erasures, visible}`，兼容旧列表/polygons/layers 格式
- **地图存档**：IndexedDB `dnd_map_db`/`map_states`（键 `dnd_map_state`、`dnd_map_state_<slotId>`）；localStorage 键 `dnd_map_state`（旧）、`_light`（≤200KB）、`_unload`、`_emergency`、`dnd_map_slots`；服务器存档 `跑团存档/地图/<name>.json`（自动存档 `_autosave`）
- 房间身份：sessionStorage `dnd_joined_room`

## 修改注意点（已知坑）

1. **时间戳版本保护**：POST/WS 均校验 `_ts`，旧状态拒绝（409 / `combat_update_conflict`），`_force` 可强制覆盖（清空场景）；前端冲突后先合并本地 3 秒内编辑再重推
2. **WS 半开降级**：`pushCombatState` WS 推送带 `_cid`，1.5 秒无 ack 自动降级 HTTP；3 秒轮询始终保留兜底
3. **空状态判断**：后端必须用 `'combatants' in state`，空数组不能当 falsy（否则清空被吞、状态回弹）
4. **作用域坑**：`_dirtyFlags`/`_pushDebounce`/`_pushInFlight`、`tokenNetData`/`textNetData` 必须留在顶层作用域（曾因声明在 boot IIFE 内导致 ReferenceError、token 旋转卡死）
5. **token 隐私**：他人 token 名称与头像均可见（`refreshTokenPrivacy` 不做显示层脱敏）；隐私拦截仅在 `canViewCharInfo`（含 `is_public`）——PL 点击他人 token 不显示角色信息面板
6. **迷雾半径**：每笔雾保存自身 `width`、擦除轨迹保存自身 `radius`（否则远程端粗细不对）；擦除为像素级挖洞，遮盖判定需排除洞内探针点
7. **缓存版本号**：改 map.js 等必须同步 bump map.html 的 `v=N`（当前 v66）；改 combat.js/combat-monsters.js 同步 combat.html `v=29`
8. 后端 `make_server` 无热重载，改后端代码需重启服务
9. 地图存档保存失败日志为 `[Errno 22] Invalid argument`（`跑团存档/地图/_autosave.json`）——曾出现，注意该目录写入权限
