# 管理后台模块

## 文件与职责

- `web/admin.py`（约 1600 行）：Flask Blueprint 挂载 `/admin/*`，统一 `@admin_required` 校验
- `web/templates/admin/`：16 个模板（base / dashboard / users / user_detail / characters / character_detail / chat / stats / errors / system / audit / backups / topics / community / content / announcements / login）

## 功能

- **仪表盘**：总览数据
- **用户管理**：用户列表/详情/编辑
- **角色管理**：全部角色 CRUD + 统计
- **聊天归档**：跑团聊天记录查看
- **统计**：事件等数据统计
- **错误日志**：查看服务端错误
- **系统信息**：系统状态查看
- **审计日志**：操作审计
- **备份管理**：备份列表/创建/下载/还原/删除（对应 `骰娘/backups/` 目录）
- **话题管理**、**社区管理**（删帖）、**内容管理**、**公告管理**、**日志清理**

## 页面路由

`/admin/login`、`/admin/`、`/admin/users`、`/admin/users/<id>`、`/admin/characters`、`/admin/characters/<id>`、`/admin/chat`、`/admin/stats`、`/admin/errors`、`/admin/system`、`/admin/audit`、`/admin/backups`、`/admin/topics`、`/admin/community`、`/admin/content`、`/admin/announcements`

## API

- `/api/dashboard`、`/api/users`（CRUD）、`/api/characters`（CRUD + `/stats`）
- `/api/system/info`、`/api/chat-archives`、`/api/event-stats`、`/api/topics`
- `/api/community/posts/<id>`（DELETE）
- `/api/audit-logs`
- `/api/backups`（列表/创建/下载/还原/删除）、`/api/logs/cleanup`

## 修改注意点

- 所有接口经 `@admin_required`（管理账号见 `初始管理员账密.txt`），改路由时勿遗漏装饰器
- 备份功能对应 `骰娘/backups/` 目录（按日期归档的代码/数据备份）
- 后台数据统计走 PG（与主站同库）
