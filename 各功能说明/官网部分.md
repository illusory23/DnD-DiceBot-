# 酒馆 / 创意工坊 / 用户中心（portal）

## 文件与职责

- `web/templates/portal/`：index.html（首页/板块）、user.html（用户中心）、post_detail.html（帖子详情）、workshop_detail.html（工坊详情）、notifications.html（通知）、announcements.html（公告）、changelog.html（更新日志，v5.3 新增）
- **JS 全部内联于模板 script 中，无独立 JS 文件**（`static/portal/` 仅图片素材）
- 公共脚本：`online-presence.js`、`announcement-banner.js`、`common-error-handler.js`

## 功能

- **酒馆社区**：分板块浏览/搜索、发帖、回帖、点赞、收藏；帖子点击进入独立详情页 `/post/<id>`
- **酒馆告示板（v5.3）**：酒馆视图顶部公告区（`loadCommunityAnnouncements`），展示全部已发布公告（`/api/announcements/history`，id 倒序+前端排序），完整内容从新到旧
- **历史版本更新页（v5.3）**：`/changelog` 读取 `骰娘/更新日志/` 目录，按日期分组+懒加载内容+全部展开/收起；首页页脚与公告页导航入口
- **每周话题**：话题浏览与帖子关联
- **创意工坊**：投稿资源、点赞/收藏/评论；投稿点击进入独立详情页 `/workshop/<id>`
- **用户中心**：注册/登录、头像与昵称修改、我的帖子、我的收藏
- **消息通知**：评论/点赞/收藏通知（未读红点，30 秒轮询刷新）
- **公告与在线**：公告横幅、在线用户状态

## 数据源（重要）

- 2026-08-15 起全量 PostgreSQL。`_load_json_file(path, default)`（app.py 约 4647 行）是 **PG 查询封装**：path==`_COMMUNITY_FILE` 读 `CommunityPost`，`_WORKSHOP_FILE` 读 `WorkshopItem`；`_save_json_file` 全删全插保留 id
- **收藏仍走 `data/favorites.json`**（`Favorite` 表已有但读取来源仍是 JSON 文件）——收藏的标题/作者必须从 `_load_json_file` 同源读取，勿改查 ORM（曾因来源不一致导致收藏列表为空）

## API

- 社区：`/api/community/boards`、`/api/community/boards/<id>/threads`（q 搜索+分页）、`/api/community/posts`（POST 发帖/GET 列表）、`/api/community/posts/<id>`（详情）、`.../like`、`.../comments`（POST/DELETE）
- 工坊：`/api/workshop/items`（GET/POST）、`/api/workshop/items/<id>`（详情/点赞/评论）
- 其他：`/api/favorites`（GET/POST）、`/api/notifications`、`/api/topics`、`/api/auth/*`（register/login/me/update-profile/avatar）、`/api/online/users`
- 更新日志（v5.3）：`/api/changelog`（文件列表，按 `YYYY-MM-DD_序号_主题.txt` 正则解析）、`/api/changelog/<path:filename>`（单个文件内容，basename+正则防路径穿越，UTF-8 errors='replace'）

## 关键数据结构

- 帖子：id/board/title/content/images/author/created_at/reply_count/comments[{id,username,content,created_at}]/likes[用户名数组]
- 工坊：id/title/desc/file_url/author/created_at/cat/comments/likes
- 通知类型：`post_comment`/`workshop_comment`/`post_like`/`workshop_like`/`post_fav`/`workshop_fav`/`mention`，字段含 group_key（聚合去重）+count

## 修改注意点（已知坑）

- **改名后通知找不到作者**：`_notify_author` 按 username 精确查 User，作者改过名会丢失通知——改名接口已同步更新帖子/工坊 author 字段，历史数据如不一致需人工处理
- 首页导航"🔔 消息通知"入口 + 未读红点（30 秒轮询）；通知列表每 30 秒自动刷新
- 帖子/工坊点击进入独立详情页 `/post/<id>`、`/workshop/<id>`（原先弹窗已改跳转）
- 自己给自己点赞/收藏不通知；同项聚合（group_key）
