# 其他小模块

## 功能总览

- **资料库**：法术/怪物/物品/规则检索
- **聊天室**：跑团聊天 + 酒馆聊天（互相隔离）
- **DM 事件系统**：事件发布/撤回/置顶、玩家通知、统计
- **Mod 系统**：外置 Mod 加载与重载
- **3D 骰子**：3D 掷骰与检定合并页、结果广播、统计
- **公共脚本**：全局错误上报、公告横幅、在线状态、事件弹窗

- **CHM 索引注意（v5.11）**：`chm_indexer.py` snippet 8000 字符（原 300 只覆盖标题+前 300 字，正文深处词条如"负重"搜不到）；编码读取 UTF-8 严格优先回退 GBK（怪物图鉴2014 为 UTF-8，GBK 宽松解码会乱码）；`build_all_indexes` 会重建 monsters_full.json——重建后必须合并保护 source='MM' 的 450 条（见 backups 流程）

- **怪物查询（v5.6 版本并存）**：`/api/monsters/search` 按 `(name, source)` 去重，同名 5e（MM）/5r（MM25）版本都展示、行内标注来源；`/api/monster/<name>?source=MM` 精确打开指定版本词条；匹配链"精确优先（自定义→CHM→SRD）→ 模糊兜底"，前端搜索对模糊命中（返回词条名与输入不一致）一律走列表确认
- **创建为角色（v5.6）**：角色卡/参考页/战斗页的"创建为角色/加入战斗"使用词条真实 HP/AC/属性，HP 按词条骰子表达式（"HP 19（3d8+6）"→ 3d8+6）自动投掷

## 聊天室（chat.html，约 1000 行）

- `/api/chat/send`、`/api/chat/messages`（跑团聊天）+ `/api/tavern/chat/send|messages`（酒馆聊天，与跑团聊天已完全隔离，勿混用）
- **在线列表手动刷新（v5.7）**：在线玩家行右侧「🔄 刷新在线」按钮 `refreshOnlineUsers()`——已加入聊天 → 主动发一次心跳（返回最新列表，被清理时自动 rejoin）；未加入 → 走只读接口 `GET /api/room/users`（后端 app.py `api_room_users`，先 prune 再返回）

## 3D 骰子

- `templates/dice3d-e.html`（约 770 行）：3D 掷骰 + 检定合并页
- `static/dice3d/dist` 与 `static/dice-engine-v3`：同一引擎的两个副本（DiceBox/DiceFactory，改动需两处同步或确认引用关系）
- `static/dice-box`：Three.js 物理引擎（Dice.js + world.onscreen.js 约 13000 行）
- 配套 API：`/api/roll`、`/api/dice-broadcast`、`/api/dice-stats`
- **混合多重骰子（v5.8）**：`core/dice_engine.py` `parse_dice_expression` 按 +/- 拆组（每组独立 XdY + k/dl/dh/!），`roll()` 逐组投掷求和；`DiceResult.groups_detail`（每组 {sides, rolls}）供 3D 动画按组构造单 @ 多组确定性格式（`1d20+1d4@17,3`，引擎 `DiceNotation` 按 + 拆组、强制结果按骰子顺序分配）；`/api/roll` 响应含 groups_detail；前端 `buildDetNotation` 优先按组构造（d100 单组仍拆 2d10），无分组信息回退旧逻辑
- **骰子统计（v5.7）**：`recordDiceStats` 只上报 **d20**（doRoll 按表达式面数过滤，`d100`/`1d6` 等不参与，杜绝误计暴击）；豁免 Tab（doSave）与暗骰也计入；暗骰仅统计不上报结果，排行榜记录 {name, roll} → `/api/dice-stats` POST（后端按 roll==20/1 计 crit）
- 掷骰检定逻辑另有 `static/dice-deterministic`（确定性骰子，供检定/回放）

## 服务启动（web/app.py run_server）

- `make_server` 无热重载；**必须同端口双监听 `::1` 与 `0.0.0.0`**（否则浏览器访问 localhost 每个连接回退等待约 300ms）
- 启动脚本：`启动骰娘跑团平台官网.bat`；端口默认 5000（config.py SERVER_PORT）
- **bat 端口清理（v5.9）**：启动前自动杀掉所有占用 5000 端口的残留进程（`for /f` + `netstat` + `taskkill /F`，2 秒等待释放）——防止新旧实例并存导致请求打到旧代码（如死亡豁免 404）；关闭窗口前台 python 随窗口退出，残留由下次启动自动清理；bat 为 **GBK + CRLF** 编码，修改必须保持（cmd 对 LF 行解析会错乱）
